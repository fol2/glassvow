## Result

All 13 controlled surfaces passed:

- omitted and explicit null settings were exact;
- the pool knob appended only the exact Duskblade unlock and uncommon carrier;
- Ashwarden pool, policy, RNG and combat state stayed exact;
- the gate changed only Afterimage production when Mirror Oath was absent;
- Ward stayed at 5, Mirror Oath satisfied the gate, and Ashwarden and Scoreline negative controls stayed exact;
- telemetry harvest left complete state, queue and RNG exact.

The first whole-run comparison then failed at policy 0, seed 346596, `pool-null-only`. Outcome and final RNG were both still `loss` and `827336654`, but fights, package events and ordered trajectory differed. The runner stopped at that first analysed failure. Its fixed Godot batch had already produced all 768 preregistered rows before Python began comparison; no adaptive row was added, and the remaining cached rows are diagnostic evidence only.

The post-failure cache audit found zero frozen-anchor-exact rows in every null arm. Nevertheless, all 256 rows were pairwise exact between every pair of the three new null encodings. This cannot rescue the preregistered result.

## Bounded diagnosis

The frozen anchor used current-main content SHA-256 `a0d608a5142d2e3aab799cdf33d3163922b402c2aaf2a895e46e096399b56cf1`. The executed preflight used candidate content SHA-256 `0aacecf001f44ffa557a868e63a28117d223d51c411ceef547a61a81acca3e76`.

Before Mirror Oath was added, that candidate substrate already differed from current main in eight package cards and four package statuses. Adding Mirror Oath changed only the `mirrorOath` card and status, and the card was absent from every base pool. This identifies an invalid historical anchor for the complete candidate substrate, while the pairwise-null result bounds the two encodings themselves. It does not establish a Mirror Oath balance effect and cannot be used post hoc to waive the frozen complete-row rule.
