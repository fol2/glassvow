## Scientific narrowing

Package definitions, local complementarity, reachability, identity, reliability,
C2/RandomBuild, Vow-5 and duration are not the remaining blocker on this exact
support. The remaining blocker is policy-selective expression: a universal
producer-first override pushes already common routes towards saturation and is
not stable enough across independently sampled policy roots.

This measured repertoire bottleneck creates decision value for a bounded
policy-sensitive structural control, but does not by itself justify repeating
the exhausted #517 whole-run latent-geometry fit or #519 matched-cost functional
kernel/QD method race. A package-specific conditional grammar using existing
payoff-preference dimensions is the cheaper next discriminator. ML/RL remains
deferred until that deterministic control is tested.

## Current authority

Close packageOrder level 1. Preregister a new identity-safe policy-selective
sequencing factor or, if it fails, continue to the next evidence-backed
structural mechanism. Do not reopen scalar selection, promote product scope,
calibrate the detector, use protected seeds or create a successor ticket.
