## Observed source delta

`audit_source.py` pins the baseline content/combat and assembled candidate bytes,
compares all top-level combat function bodies and every existing domain file,
and resolves base/upgraded definitions before comparing an explicit combat-card
projection. Unknown card fields, hit multiplicity and added draw effects are not
erased. The projection deliberately excludes names, text, VFX, rarity and unlock
metadata; that is why its equality is NOT whole-game or acquisition equivalence.

The candidate retains 52 combat function bodies, including action dispatch,
hit accounting, chips, coupled Shatter, turn progression and draw. Only the special
dispatch and preview functions change; `resource_payoff` is added. Every other
existing domain file is unchanged. Non-card content changes include card pools,
Ashen Core and Ashfall, and cannot be assumed irrelevant to every context.

For the fixed Chisel/Resonant Lance motif, both base and upgraded combat-card
projections and the Echo special arm are identical. Lance changes rarity only.
Therefore the claim that this pair introduces a new Echo primitive is rejected.
This is not a proof that altered acquisition or a separately specified larger
package cannot have value, and it is not the whole closed-family quotient.

For Cycle, the same-instance growth arm and CardInst lifecycle are unchanged,
but native draw 1 is appended and n/grow/rarity change. The complete action is
NOT equal to the original Honing Edge action. A proof concerning decomposition
and feedback is still necessary; neither lexical inheritance nor scalar erasure
is a full behavioural-equivalence proof.
