# P9 v15: matched build controls, unchanged candidate

Status: EXPLORATION_NOT_P9. No product promotion or acceptance change.

## Why this experiment

The completed v14 paired comparison found 110/192 greedy wins and 138/192 native-rollout wins. All six Vow-5 cells improved on that small exploratory cohort, but two Vow-0 cells declined and native planning cost approximately 20-34 times greedy. Before doing expensive package admission, test whether competent random building also benefits and erases the build-choice distinction.

## Mechanical throughput change

The public-state cloner now caches the script-variable field-name list for each fixed GDScript instead of allocating it on every clone. No state field is omitted or numerically changed. In native tests, 72 full-property/transition/isolation assertions passed. Eight alternating clone timing batches measured approximately 0.43-0.51 times the old cloning time; this is a cloning microbenchmark, not a claim that complete runs are twice as fast.

Twenty-four complete native run records (two original v14 seeds for every route/vow) were then byte-equivalent as parsed records, including outcomes, decks, actions diagnostics, fights and mechanism counters. These are regression replays, NOT new independent scientific samples. Old v14 receipts remain immutable and retain their original observer identity.

## Frozen design

Content remains de41f69c9cd28cbd09e16880450957b80675f21b53125cd68a42594e41fbf747. Official engine and product reference are unchanged from v14. There is no content choice based on the new control outcomes.

Six controllers, vows 0/5, planned versus route-matched RandomBuild; 32 assigned seeds 14020000..14020031 for every condition. Total 24 cells and 768 whole-run condition evaluations. Both arms use the same native combat procedure (two public determinizations, twelve continuation steps), same card values, same route-specific parameters and bank_mode=current-plus-next. RandomBuild randomizes the existing named build surfaces, not combat competence. Early deaths and all adverse outcomes remain assigned. No protected acceptance seeds.

Freeze actual source/content/configuration identities before execution. No edits while the batch runs. Per-invocation watchdog is 1800 seconds; it is containment, not an owner-quota checkpoint. A timeout or native error is retained as incomplete evidence, never silently excluded or relabelled a loss to pass a gate.

## Readout and boundaries

Report each route's paired build contrast, all route rates and mechanism use. Summarise the top planned rate and sampled RandomBuild rates by aspect/vow, but do not treat a sampled maximum as a universal ceiling. Original C2 is top-cell based; a 35-percentage-point gap is not imposed independently on every route. These research controllers are not silently substituted for the signed acceptance arms.

This is a fresh, predeclared exploratory control test, not the final corrected confirmation or causal admission. If random-building remains generically strong, investigate the source of that strength before another broad retune. If the content supports meaningful build differentiation, proceed to the smallest mechanism intervention that can falsify each named package, then unrestricted retention and held-out detector testing. Six names or positive win-rate contrasts do not finish P9.
