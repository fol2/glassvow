## 2. 《退位儀式》 (The Abdication Rite)

**Film DNA**:Shutter Island:成個世界係一場為主角一個人而設嘅角色扮演,所有人都知情、都做緊戲,目的係令佢自己行到嗰個佢一直拒絕嘅真相前面。借法:三 act 朝聖係 Vigil 眾人一次又一次重演嘅「退位儀式」,而病人係你——The Eternal Sovereign 本人。

**Logline**:你以為自己係一次又一次上去弒王嘅朝聖者,直到成個世界除低面具跪低——原來王一直喺樓梯下面,係你。

**結局先行**:先設計嘅最後一幕:第六 Shard unsealing,mural 六格全亮嗰刻,在場所有 NPC(蒙面 merchant、fleshTrader、骷髏 gambler、tidecaller、掌燈人)逐個除低面具——下面全部係蒼白面容——然後跪低,面向嘅唔係道門,係你;mural 輪轂拱門暗落去變成 mirror.png:鏡中黑影人發光眼淺笑,而佢嘅剪影同 sovereign.png 完全重疊。真正終幕:除冠行入門=ascended.png(黎明之城迎返佢失落嘅王);戴返個冠=fallen.png(黑曜大廳,臣民喺碑腳留一盞燈,儀式下個 run 再嚟)。反轉全句:「你每次上去斬嗰個王座上嘅嘢,係你自己披喺鎖上面嘅形;真王由第一日起就喺樓梯下面,揸住盞燈——成場朝聖,係你嘅子民第 N 次陪你行嘅退位儀式。」

**反轉本體**:玩家係 The Eternal Sovereign。好耐之前你攞咗一盞空燈籠、將王者嘅形披喺道門嘅鎖上面,自己封死咗成個世界嘅出口;蒼白眾同 Vigil 所有角色係你嘅子民,佢哋設計咗一場可以無限重演嘅朝聖儀式——換裝、派 whisper、逐格點窗——目的唔係殺你,係氹你自己行上去、親手拆穿個假王、最後自願除冠。揭後回讀:hero 蒙面無臉同 sovereign.png 無臉係同一張「冇面」;每次 run 打嘅 Sovereign 只係道具面具;merchant 同 fleshTrader 全部戴 pale 面具因為佢哋落妝先係真面目;開場嗰下「著袍」原來係「著龍袍」;連敗仗都係「今次儀式又失敗,執返個台」。

- **起**:開場喺 Vigil:蒙面 merchant 幫你扣好兜帽、遞上燈籠流星錘,鞠躬——低咗半寸,耐咗半秒。掌燈人喺 Rose Window 六個空格前面講:「東面有個假王,同埋一道俾佢封住嘅門。」第一句 whisper 落。反轉前呢幕係英雄着裝;反轉後係朝臣服侍君主更衣,嗰半寸鞠躬係宮廷禮數收唔住手。
- **承**:六 quest 係儀式嘅六個站:蒼白眾公然指上(佢哋係提場,唔使遮掩);自身之影係歷次失敗儀式留低嘅你,所以每個影都用你嘅招;篡位者 quest 係儀式核心一課——俾你親手用無焰提燈拆穿個道具王,教識你「個冠係假嘅」;第八凶兆係佢哋加落七個之外嘅記號,焗你喺門影下打一場、抬一次頭;無法辨讀之頁其實係儀式劇本,捱過五場先俾你讀;掌燈人五個代價係逐件剝走你嘅「王產」(embers、金、血、boon、燈火),等你行到門前一無所有——一個冇嘢好守嘅王先除得低個冠。
- **轉**:第六 Shard unsealing scene:六格點齊,眾 NPC 除面具、露出蒼白面容、向你跪低;mural 輪轂拱門化作 mirror.png,鏡中發光眼黑影淺笑,剪影同 sovereign.png 重疊,再同你重疊。掌燈人最後一個除面具,講反轉全句。門開,但門唔係出口——係你王座背後嗰道你封咗嘅門。
- **合**:Act IV【加冕之前】五節點:行入你封印嘅世界——加冕之前你屬於嘅地方,九敵係唔肯散場嘅儀仗(冠、杖、袍化形)。終戰 boss【不肯除冠嘅你】:最後一個影,着住完整王袍,用鏡像招式,打贏佢=打贏自己嘅不甘。結局:除冠行入去,ascended.png——黎明之城唔係天堂,係你退位後先入得返嘅家;或者戴返個冠封返道門,fallen.png——臣民喺黑曜大廳碑腳留一盞燈離開,下一個 run,儀式由頭嚟過(roguelite 迴圈 diegetic:每個 run 都係又一次 intervention)。

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「The Sovereign is a mask worn below the final stair.」→ 反轉後成句變晒字面:王座上真係得一個「mask」——件道具,「worn」係披喺鎖上面;而真正戴住王者身份、行緊最後一段樓梯嘅,係樓梯下面提燈嗰個你。
- 「The mask is broken. Look above.」→ 反轉前係假王死前嘅怪異遺言。反轉後係提場對白:面具着(戲服)每次俾你打爛,入面嗰個蒼白眾義工照劇本提你「望上面」——望你自己封嗰道門,望你唔肯認嘅嗰樣嘢。
- 「The Pale Ones are not hunting you. They are pointing upward.」→ 反轉後:佢哋梗係唔會獵殺你——你係佢哋個王。指上唔係預言,係成個儀式唯一嘅目的:引你自己一步步行上去,行到肯除冠為止。
- 「Each climber leaves a shape behind.」→ 反轉後:歷次退位儀式嘅 climber 由頭到尾都係同一個人——你。所以沿路每個影都用你 aspect 嘅招,招名全部「憶中○○」:全部係你上幾次儀式嘅殘留。

**Act IV 概念**:新 region【加冕之前】:門後係加冕之前嘅世界——未成形嘅琉璃,熔融、透光、未上色,同三 act 嘅彩繪成對比。九敵係化形儀仗(浮冠、遊杖、空袍),boss【不肯除冠嘅你】用 mirror.png 語彙:黑影、發光眼、你嘅完整招式表。五節點入面有一節係「無戰鬥嘅覲見」:蒼白眾列隊送行,逐個講一句佢哋喺儀式入面做過嘅角色。

**敗仗殘留 (A3)**:每次敗仗,骷髏 gambler 喺 Vigil 更新佢塊粉牌:「第 N 場,冧喺【沉沒之城】,賠率照舊」——死喺邊、輸俾邊個 boss 都上牌;第二次同佢見面起佢會明文提返上次(「上次都係嗰條喉吞咗你」)。反轉前讀係賭鬼講風涼話,反轉後讀係儀式紀錄員記低第 N 次失敗嘅 intervention,同一句嘢兩個溫度。

**風險(agent 自報)**:兩大風險:一,同 baseline C 一樣以 Sovereign 做支點(C 係「王=第一個朝聖者頂住門」,呢個係「王=你,世界=做戲」——機制唔同但主持人多數只能二揀一);二,Shutter Island 式「全部係戲」好易 deflate 三 act 嘅 stakes,必須守住「代價全部係真」呢條線(HP、embers、死亡真扣真痛),戲係真戲、傷係真傷,先至企得住。
