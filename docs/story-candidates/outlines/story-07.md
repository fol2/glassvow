## 7. 《《一團火嘅第七份》》 (The Seventh Piece of the Flame)

**Film DNA**:Moon——Sam 發現自己係耗材複製品,「返屋企」係公司對每一代 Sam 講嘅同一個謊;借佢「主角本人就係一直付緊嘅代價,而個制度日日喺佢眼前運作」嘅機制:Vigil 每次『復活』你,其實係點着下一份燃料。

**Logline**:一個無臉朝聖者一次又一次由 Vigil 出發送 shard 去開門,最後發現六塊 shard 由一團火切出——而佢自己就係嗰團火淨低嘅第七份,每一次 run 燒嘅都係佢自己。

**結局先行**:最後一幕用 emberglass-mural.png:六格全亮,輪轂中央嗰道發光拱門打開;hero 除低兜帽——冇面,得胸口一粒琥珀核心——核心離體升上輪轂,成為第七點光,原初之火重燃。反轉全句:「六塊 shard 由一團火切出;你係第七塊,亦係最後一塊——你一直用嚟開門嘅火,就係你自己。」勝局接 ascended.png(原火重燃後由窗望出去嘅黎明之城),敗局接 fallen.png(碑腳孤燈=又一代燒賸嘅你)。

**反轉本體**:hero 唔係「攞住燈籠嘅朝聖者」,而係「俾燈籠揹住嘅火」:Vigil 每次 run 由 Rose Window 爐心點一份殘焰着落套兜帽袍度,死亡=火熄,「返 Vigil 再嚟」=點着下一份,你嘅連續性由頭到尾係假嘅。揭後回讀:兩個 aspect 都無臉、胸口/帽入面得一點光——證據一直畫喺 hero 身上;武器本身係燈;蒼白眾係燒盡嘅前代你(pale 係燃盡嘅色),point upward 因為未送到;keeper 冇樣因為佢只係點燈嗰隻手;Lamplighter 五個代價係示範「你係一盞可以被扣減嘅燈」。

- **起**:開場喺 Vigil:冇樣嘅 keeper 喺 Rose Window 下面點着玩家胸口嗰點光,講一句「Carry it east.」——玩家以為攞到使命,其實目擊緊自己出世。鏡頭掃過六格未亮嘅 mural 同黑住嘅輪轂拱門。Onboarding 教「死咗返 Vigil」嗰陣,keeper 每次都重複點燈動作:日日做,冇人覺得出奇,呢個就係擺喺觀眾眼前嘅代價。
- **承**:Pale Ones=收九代你嘅殘燼;Your Own Shade=舊火留低嘅衫形(「Each climber leaves a shape behind」);Usurper 嘅無焰提燈預示「空殼同火可以分離,而空殼都係鎖匙一半」;Eighth Omen=門影落咗喺你團火上;Unreadable Page 直接揭「六 pane 由一團火切出」但玩家未識驚。Lamplighter 五個代價逐步扣你 embers、金、HP、boon、燈籠 HP——每次交易都係綵排「你係燈」,最後佢講「Light the panes. The door will know you.」,因為門認得同源嘅火。
- **轉**:第六 Shard unsealing scene:六格全亮,拱門仍然唔開。keeper 行埋嚟,唔係攞 shard,而係伸手向你胸口;側用 mirror.png 語法——玻璃反影入面你見到自己真身:一件企喺度嘅袍,入面一團火。keeper 講:「Six were scattered. One was kept burning.」玩家至此先明第七份一直喺自己度。
- **合**:Act IV【爐心之路】(placeholder):行入 Rose Window 之後嘅玻璃內側,五節點由窗面行返去原初火嘅空爐;九款敵人係「唔肯歸位嘅殘焰」,boss【守灰者】=想永遠困住原初火、令朝聖無限重複嘅嗰樣嘢——即「上面嗰樣嘢」係一個等緊火歸位嘅空爐。終戰勝出,你自願歸位,mural 輪轂補上第七點光,接 ascended.png;戰敗接 fallen.png,碑腳孤燈係燒賸嘅呢一代你,等下一次點着。歸位後 roguelite 迴圈唔停:之後每次 run 係「新一份火知情咁行」,重複由謊言變成自願。

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「A lantern without flame is still a key.」→ 反轉後係講你個殼:無火嘅燈籠(兜帽袍)本身係鎖匙嘅一半;倒轉嗰下——有火無燈——嗰團火先係真正開門嗰樣,即係你。
- 「The first keeper gave you a boon. Give me the gift, not the gratitude.」→ keeper「俾」你嘅嗰份禮物,就係你出世嗰下胸口嘅火;Lamplighter 攞返「份禮物」而唔要感激,係細規模綵排最終嗰次交還——佢一早知你係乜。
- 「We were never climbing out. We were carrying light to the lock.」→ 唔再係比喻:「we」=歷代被點着嘅你,「light」=你胸口嗰第七份;朝聖由頭到尾係送火歸位,唔係逃亡,影早就講晒出嚟。
- 「The Pale Ones are not hunting you. They are pointing upward.」→ 佢哋係燒盡嘅歷代你——唔追你,因為你就係佢哋嘅下一棒;指上,係指住大家都未送到嘅同一個爐位。

**Act IV 概念**:【爐心之路】:Rose Window 玻璃內側嘅世界,五節點由彩玻璃紋理漸變成空爐嘅純黑;九敵=拒絕歸位嘅殘焰(各對應一種被燒去嘅記憶形態);boss【守灰者】=空爐嘅守門者,想朝聖永遠循環落去。全部係空白位新設計,唔掂現有美術,mural 輪轂拱門做出入口。

**敗仗殘留 (A3)**:每次敗仗,Rose Window 腳多一粒 pale mote(該 run 嘅殘燼),keeper 下次點燈前用一句完整散文記低「上一份火熄咗喺邊、熄之前做過乜」——玩家遲早發現自己一直收集嘅 motes 同呢啲一模一樣。

**風險(agent 自報)**:「你唔係你以為嗰個」同 baseline B 表面相似,必須靠「燃料/耗材+連續性本身係謊言」嘅機制拉開;hero 無臉呢條證據好當眼,部分玩家會早估中(Moon 本身都係半揭面設計,估中唔傷回讀,但會削 zyun 嘅震撼);結局要玩家「自願歸位」有被劇本挾持嘅風險,靠勝/敗雙圖同知情重複去對沖。
