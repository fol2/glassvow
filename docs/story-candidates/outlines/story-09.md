## 9. 《《被抵押嘅黎明》》 (The Pawned Dawn)

**Film DNA**:The Prestige 嘅「You want to be fooled」+ Moon 嘅制度成本外判:魔術每場都燒緊道具,觀眾唔會問個籠入面隻雀去咗邊——呢度隻雀係成個世界嘅日光,而佈景(三個 act 嘅美術)由第一秒就係張賬單擺喺你眼前。

**Logline**:朝聖者以為自己穿過一個早已毀滅嘅世界去開門,最後發現次序掉轉:六塊 shard 係由世界個光環切出嚟,而每一次 run,道門都收一次過路費——由佈景找數,世界一直暗落去。

**結局先行**:最後一幕:玩家穿過 emberglass-mural.png 輪轂嘅發光拱門,門外係黎明;然後回頭——身後個世界係 fallen.png(黑曜大廳,碑腳一盞孤燈,即世界燒剩嘅最後一點光)。反轉全句:「門後面唔係寶物,係個世界俾人沒收咗嘅日光;你以為朝聖係穿過廢墟——朝聖先係整廢墟嗰樣嘢,每一步嘅路費,一直由佈景找數。」

**反轉本體**:六塊 emberglass 唔係「散落」,係由世界個光環——act3 天上嗰個斷開金環——切出嚟;切嗰下世界開始暗:樹林燒成灰、城沉入黑水、終境剩返黑曜。之後每次 run 道門再收一次費,所以 roguelite 嘅重複唔係中性機制,係持續放血。揭後回讀:三個 act 嘅美術由「氣氛」變「賬單」;act3 全部敵人帶斷環,唔係怪物係守喪人;Leviathan/deepmaw 用假光誘餌=真光被抽稅後生態嘅病徵;Sovereign 斷 halo 缺一塊=世界斷環嘅縮圖,佢係首任守光人,王冠只係面具;由西向東嘅橫向地圖=一條愈行愈暗嘅收費梯度。

- **起**:開場喺西面 Vigil——全地圖唯一仲有暖光嘅地方;keeper 話「東面愈嚟愈暗,要有人去睇下點解」,玩家以為自己出發去拯救。出門嗰刻留一粒 detail:Vigil 爐火細咗一格。第一 run 嘅每一步,其實都幫個世界簽緊單。
- **承**:Pale Ones 指上=指住被沒收日光嘅原位(斷環);Your Own Shade=你上次 run 燒低嘅痕;Usurper 嘅無焰提燈係全遊戲唯一唔使收費嘅光,用佢拆穿假王本身就係題眼;Eighth Omen 嘅「門影」=三個 act 嘅暗係字面上道門投落世界嘅影。Pages 揭「六 pane 由一團火切出」——嗰團火係世界日光;Lamplighter 五個代價(embers、金、HP、boon、燈)係佢細規模示範門嘅收費文法,因為佢認嘅罪係:當年執行切割嘅人就係佢。
- **轉**:第六 Shard unsealing:六格亮起嗰刻,Vigil 爐火熄——成個遊戲最後一盞真光移咗上窗。keeper 企喺黑入面讀出:「Count the panes that do not catch the dawn.」玩家至此先醒覺:panes 唔會 catch dawn,因為 panes 就係 dawn。
- **合**:Act IV【日蝕金庫】(placeholder):門後係收埋所有被沒收之光嘅金庫,五節點由全黑行返入光;九敵=「利息」(食世界失去嘅嘢養大嘅光蛭類);boss【收費者 The Toll-Keeper】=「上面嗰樣嘢」,一直隔住玻璃收數嘅嗰隻手。勝=打爆金庫,光沿 mural 輪轂倒流返落世界,ascended.png 讀成「還款之後嘅黎明」,並且之後每次 run 三個 act 用 runtime tint 各還返一線光;敗=fallen.png:你自己都入咗賬,碑腳孤燈係世界暫時淨返嘅全部。

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「There is a colour the Spire refuses to name.」→ 嗰隻唔肯名嘅色就係日光色:成座【終境】係用沒收返嚟嘅光起嘅,名咗出口就等於認罪——第 0 句 whisper 原來係成單案嘅供詞開頭。
- 「Count the panes that do not catch the dawn.」→ 由謎語變指令:panes 永遠唔會 catch dawn,因為 dawn 已經俾人切成 panes;「數唔亮嗰啲」=數緊仲爭幾多先贖得返個天光。
- 「THE EIGHTH OMEN WAS NEVER AN OMEN. IT WAS THE SHADOW OF A DOOR.」→ 完全字面化:三個 act 嘅暗全部係道門投落世界嘅影;凶兆從來唔係預告災難——道門企咗喺光同世界之間,災難就係道門本身。
- 「Five pages make a chapter; five prices make a confession.」→ 「confession」實指:Lamplighter 五次收費係佢重演當年切割世界光環嘅五刀;佢空咗(hollow),因為第一個俾門抽走光嘅就係執行者自己。

**Act IV 概念**:【日蝕金庫】:收藏被沒收之光嘅庫房 region,美術語彙=黑曜框住嘅過量金光、倒懸嘅斷環殘件(呼應 act3 mid 嘅浮環+水晶);九敵=利息化形(樹林嘅綠、城嘅潮汐、名字、顏色等被支付之物嘅光蛭);boss【收費者】隔住一塊巨型玻璃作戰,打爛玻璃=開倉還光。全屬空白位,唔改現有 asset。

**敗仗殘留 (A3)**:敗仗後該 run 行過嘅 region 用 runtime tint 永久暗一格(美術本體不改),Vigil 散文記低「呢次朝聖,世界又找咗一次數:失去咗【某樣嘢】」——玩家每次輸,望返地圖都見到自己嗰筆賬。

**風險(agent 自報)**:呢個反轉冇「你係乜」嘅 personal punch,情感力度全押喺世界悼亡上,對部分玩家會偏凍;「集 shard=做緊壞事」同 baseline C 有表面重疊,要靠「代價=世界、Sovereign 只係佈景一部分」保持距離;backdrop 漸暗/還光必須用 runtime tint 或 overlay 實現(asset 不可改),實作有額外工程成本,而且「愈玩世界愈暗」對 retention 係一個真風險。
