## 11. 《《玻璃記得將來》》 (The Glass Remembers Forward)

**Film DNA**:Arrival——借「學識一種語言之後,記憶唔再單向」:讀通 emberglass 之後,玩家以為嘅遠古紀錄全部變成 flash-forward;情感核心照借「預知晒成個結局、包括入面嘅失去,仍然揀行落去」。

**Logline**:朝聖者以為自己喺度修復一場遠古嘅碎裂,學識讀玻璃之後先發現:碎裂根本未發生,打碎個窗、散落六塊 shard 嘅人就係佢自己——而遊戲開場嗰幕,先係成個故事嘅結尾。

**結局先行**:最後一幕:玩家步入 emberglass-mural.png 輪轂中央嘅發光拱門,白光一閃,接返 title 畫面嘅燈火螺旋,鏡頭沿螺旋跌落——落返喺開場嘅 Vigil scene:Rose Window 空空如也,「Six spaces wait where no window stands」。玩家認出:呢幅唔係重播,係第一次。反轉全句:「六塊 pane 係你而家先至打碎、親手散落返去『第一次 Vigil 之前』;你玩過嘅每一個 run,全部發生喺開場畫面之前——開頭就係結尾。」

**反轉本體**:反轉:emberglass 係一種令記憶雙向嘅語言。集齊六塊之後玩家先識「向前記憶」,並發現 Unreadable Page 全部係未來式:page 1 嘅「喺第一次 Vigil 之前被散落」入面,「第一次 Vigil」喺將來,散落 shard 嗰個人係完成朝聖嘅你。揭咗之後要重讀:所有 whisper 唔係遺跡考據,係倒數緊嘅預告;heraldOfEnd 一直咁驚,係因為佢同你一樣記得將來;第八凶兆「係一道門嘅影」=時間下游嘅事件投落上游嘅影;act3 嘅斷金環係未閉合嘅時間圈,集齊六 shard 就係閉環嗰下。

- **起**:開場(其實係時序上嘅結尾):Vigil,空窗,keeper 話「六個位一直等緊」。第一個 run 落山,heraldOfEnd 第一次見你就跪低,揹住嘅裂號角震緊:「你嚟喇。我記得你會嚟。」——第一次見面就『提返上次』,rubric 嘅 recurring 規則喺呢度倒轉用,本身就係伏筆。
- **承**:六條 quest 掛做「學讀玻璃」嘅六堂課:蒼白眾 pointing upward 指嘅唔係方位,係時間上游;自身之影係其他 run 嘅你滲入呢個 run(招式叫「憶中○○」,因為記憶已經開始跨 run 流動);Unreadable Page 每揹一場多熟一分,「survives the summit」先讀到=未來式文字要等事件發生先成立;第八凶兆條線由「凶兆」重讀成「投影」;Usurper 嘅假王係圈入面一個行錯咗嘅舊你;Lamplighter 喺路上五個唔同位置收費,其實係同一個人喺圈嘅五個時刻收同一筆數,所以佢永遠知你下一步。
- **轉**:第六 Shard unsealing scene:六格全亮,page 5 應驗——「Rose Window 係地圖,唔係紀念碑」:窗上顯示嘅唔係地形,係時間嘅圈:西→東→門→散落→西。玩家第一次向前記憶:未打贏第 24 場,已經聽到 whisper 23「The climb continues」喺耳邊響。鏡頭一 cut,act3 backdrop 嗰個斷開金環喺遠景慢慢合攏。
- **合**:Act IV【環外】:門後係時間之外嘅一段短廊,五個節點每個係你一個舊 run 嘅玻璃殘影(用已擊敗 boss 嘅彩玻璃幽靈形態,重用現有 boss 美術),行過去=逐個同自己嘅過去道別。終戰 boss【首夜人】:page 3 嗰個「站着死去、見到終點之上仲有一段梯」嘅朝聖者——佢喺你之前行完呢個圈,而家企喺門口問你同一條問題:明知點完,你仲揀唔揀行?揀行=你打碎個窗、散落六 shard、步入拱門,接 title 螺旋、接開場 Vigil(閉環,主結局,mural 光調);揀唔行=圈斷開,接 ascended.png 做「圈外第一個黎明」,但 Rose Window 六格永暗,樂而近悼。

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「A page can be read only after it survives the summit.」→ 反轉前似講「頁要保存完好」;反轉後係時態規則:頁係未來式寫嘅,佢描述嘅事件(summit)未發生之前,啲字根本未『成立』——讀唔到唔係墨水問題,係時間問題。
- 「Broken glyphs are the shadow of a complete sentence.」→ 完整嗰句一直存在——喺時間之外;你沿途見到嘅碎 glyph 係佢投落線性時間嘅影。同第八凶兆嘅『IT WAS THE SHADOW OF A DOOR』係同一套物理:上游見到嘅全部係影。
- 「The dead climb twice: once in flesh, once in memory.」→ 兩次攀登唔係先後兩次,係同一次由圈嘅兩邊睇——而『in memory』包埋向前嘅記憶:你而家呢次,對圈另一邊嘅你嚟講已經係『in memory』。
- 「The climb continues.」→ 第 24 句唔係鼓勵語,係字面陳述兼接口:圈冇終點,whisper 23 讀完直接駁返 whisper 0——廿四句本身圍成一個環,同斷金環合攏係同一件事。

**Act IV 概念**:【環外】:時間之外嘅短廊,美術方向係「所有 run 同時存在」——背景同時見到三個 act 嘅地貌互相穿透,彩玻璃層層透疊。九隻敵人=你歷次 run 嘅玻璃殘影(重用/變調現有敵人美術做幽靈化),boss【首夜人】係 page 3 站死朝聖者,企姿即係佢嘅碑,呼應 whisper 10。

**敗仗殘留 (A3)**:每場敗仗即刻被「已記載化」:返 Vigil 時 heraldOfEnd 或 journal 用過去完成式覆述你啱啱嘅死法(「我早就記得你呢次跌喺 Sunken City」),指明地點同死因——敗仗唔係意外,係圈上一個早已寫低嘅節點,而你而家先行到嗰頁。

**風險(agent 自報)**:三個之中最燒腦:run-based 節奏下玩家隔幾日先玩一次,時間圈好易斷線,必須靠 whisper 順序同 herald 呢條單線死揸住 pacing;另外要同 Predestination 式「邊個生邊個」保持距離——重心一定要係『預知仍揀』,唔係解謎邏輯,否則變咗智力遊戲冇咗 Arrival 個心。
