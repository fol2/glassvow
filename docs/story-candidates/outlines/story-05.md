## 5. 《立亡者》 (The Unfallen)

**Film DNA**:Source Code:成個重複迴圈其實發生喺一個垂死者嘅最後一刻入面,任務係喺重播中搵出唯一正確嘅一次;搵到嗰下,重播升格做真實。呢度將「八分鐘列車」換成「燈籠最後一格火」——每個 run 都係死火前嘅一次重播。

**Logline**:你以為自己死完又死;其實你喺終點企住死咗好耐——成條朝聖路,係你燈籠最後一粒火星入面重播緊嘅記憶,搵緊嗰一條可以點齊六 pane 嘅路。

**結局先行**:最後一幕用 fallen.png:黑曜石碑大廳,碑腳一盞孤燈——揭穿嗰下,鏡頭升起,石碑輪廓同 hero 剪影重疊:碑就係企住死嘅你,孤燈就係終於放得低嘅燈籠。反轉全句:「你冇喺條路上死過一次。你喺呢度企住死咗好耐——條路,係你燈籠裡面最後一格火重播緊嘅嘢。」coda 用 woundedKnight.png:嗰隻手終於垂低,向新到嘅朝聖者遞出琥珀水晶——玩家先發現 Act II 見過嘅垂死騎士 event,一直係結局嘅預告,遞水晶嘅係自己。

**反轉本體**:肉身早喺故事開始前已經企喺終點死去(頁三嗰個「站着死去嘅朝聖者」係第一身唔係第三身);Vigil、死亡回歸、24 句 whisper,全部係垂死之火嘅內部重播——whisper 係肉身臨終聽落嘅碎念,影係失敗重播嘅殘形,鏡中笑住嘅黑影係「重播之外」嘅真身。揭後回讀:roguelite 迴圈由 game mechanic 變 diegesis 本體;Source Code 式救贖在於——當六 pane 喺火中點齊,重播唔再係重播:火行返入肉身,身倒下,手張開,shard 交畀下一個真實嘅朝聖者,搵到嗰條路成為真。

- **起**:正式開場前閃一格:黎明逆光、一個人形企喺峰頂——一秒都無就切走。然後先係 Vigil「醒來」、keeper、燈籠、向東出發嘅正常 onboarding。早期 mirror.png event 照常出現:鏡入面嗰個發光眼黑影淺笑望住你,唔講嘢——玩家當佢係不祥,其實佢係鏡外嘅真身。
- **承**:六條 quest = 垂死之火嘅六個搜索條件,每條隔離一件「必須重新點着嘅記憶」:蒼白眾=肉身企喺終點時望住路過嘅其他朝聖者最後嘅光;自身之影=三次失敗重播嘅殘形(招名「憶中○○」係字面);篡位者=肉身生前信錯嘅假希望;第八凶兆=油盡燈枯嘅閃爍節拍,「八」係門影橫過垂死眼簾;五頁=企住死嗰段時間諗通嘅五件事;掌燈人五個代價=火同自己講數,逐樣放低(將來、財、肉、初贈、淨一格火)先可以繼續燒——佢尾句「Light the panes. The door will know you.」係肉身留畀自己團火嘅最後指令。
- **轉**:第六 pane 亮起嗰下,Vigil 場景明顯「跳格」——同一拍重播咗兩次,玩家第一次親眼見到世界係重播。鏡隨即向外碎開,露出真實時刻嘅峰頂黃昏:企住嘅人形,手中燈籠淨返一粒火星。keeper 講:「接落嚟呢程,唔係再一次——係嗰一次。」由今個 run 起,重播已搵到條路,而家要喺最後一粒火星入面真係行返一次。
- **合**:Act IV【燼梯】——頁三講嘅「終點之上嗰段梯」,喺最後一粒火星入面展開,五節點:(1) 世界邊緣開始燒燶、重播失去餘裕;(2) 掌燈人最後一面,明文認返五個代價其實係肉身逐樣放手(recurring recall);(3) woundedKnight 一幕倒帶重演,兜帽揭開係你嘅面具;(4) 鏡中黑影行出嚟,無言同行;(5)【不倒者】——你嘅肉身,被誓約鎖住企喺門前唔肯倒。終戰勝利=火行返入身。結局:身終於倒下、手張開遞出第六 shard,fallen.png 孤燈立碑,末句「The dead climb twice.」之後,大廳入口浮現下一個朝聖者剪影,接 whisper 23「The climb continues.」

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「Your monument does not always lie down.」→ 完全字面:你嘅紀念碑企緊——因為石碑就係你企住死嘅屍身;呢句由怪誕謎語變成劇透本體。
- 「The dead climb twice: once in flesh, once in memory.」→ 第一次係肉身嗰程(真實發生、以企住死終結);「in memory」唔係比喻——玩家打嘅每一個 run 就係第二次,喺記憶入面爬。
- 「Each climber leaves a shape behind.」→ quest 2 嘅三個影就係之前失敗重播留低嘅殘形;「shape」係重播殘影嘅準確描述,招名全部「憶中○○」一早寫明晒。
- 「有個朝聖者站着死去,見到終點之上仲有一段梯」→ 頁三一直用第三身讀;揭後變第一身——嗰個朝聖者係你,嗰段梯就係 Act IV【燼梯】,而「見到」嗰下就係成個遊戲發生嘅時刻。

**Act IV 概念**:新 region【燼梯】:峰頂之上、火星內部嘅一段梯——幾何邊緣燒燶、背景係放大嘅燈芯同玻璃熔光。九敵=前三 act 敵人嘅「燒剩」白燼變體(記憶燒緊嘅殘形,美術上可重用剪影+燼白 palette)。Boss【不倒者】:玩家肉身本體,持熄燈、誓約鎖姿,唔攻擊為主而係「唔肯倒」——打法係解鎖而唔係擊殺。

**敗仗殘留 (A3)**:每次敗仗=一次重播熄火:鏡面(Vigil 面鏡/mirror event)多一道裂紋,而該次敗走嘅 run 會具體化成 quest 2 世界觀下嘅影——之後遇到嘅影會用返你敗嗰 run 用開嘅牌型招式,「憶中○○」直接指涉該敗仗;keeper 講返「上次你熄喺(地點)」。

**風險(agent 自報)**:呢個係三個入面最近「原來係一場夢」嘅家族,groan 風險最高——必須靠 Source Code 式「搵到嗰次成為真+交棒下一個朝聖者」先至唔會貶值玩家每一個 run;另外佢將 Vigil 判定為「非真實」,同跨 run 據點嘅安樂窩感有張力,Vigil 文本要寫到「重播中嘅家」都有溫度先接得住。
