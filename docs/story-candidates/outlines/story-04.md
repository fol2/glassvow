## 4. 《自書之誓》 (The Vow That Wrote Itself)

**Film DNA**:Predestination:自我成因嘅閉合迴圈——主角追尋嘅源頭就係自己。呢度借「炸彈客=特工=自己」嘅結構:門上嘅誓言、散落六 shard 嘅嗰隻手、「上面嗰樣嘢」,三者全部係玩家自己喺迴圈另一端嘅同一個動作。

**Logline**:朝聖者行到封門前,發現門上等咗比 Vigil 更耐嘅誓文係自己親手寫低——而開門呢一下,正正就係當初六塊 shard 被散落嗰一下。

**結局先行**:最後一幕用 emberglass-mural.png:六格全亮,輪轂正中嘅發光拱門打開——但門後唔係彼岸,係由上空俯瞰嘅 Vigil 黎明,鏡頭穿過拱門、由 Rose Window(rose_window_view)嘅背面走返出嚟。玩家親手將六點火星向西撒落地圖(開場神話嗰一幕,而家先知係邊個做)。反轉全句:「道門唔係出口——道門係起點;你而家開門呢一下,就係六塊 shard 當初被散落嗰一下。門上嘅誓言,係你自己嘅手筆。」

**反轉本體**:Rose Window 同「冠冕之上嘅封門」係同一面窗嘅兩面:Vigil 唔係喺終點西面,係喺終點之上。「上面嗰樣嘢」就係你——迴圈原點嘅你,將自己嘅燈火切成六塊、寫低誓言封門、然後無記憶咁向西出發。揭後回讀:六條 quest 線唔係六件奇聞,係誓文嘅六句;掌燈人五個代價唔係勒索,係逐層剝走「唔屬於原焰嘅嘢」;每次死亡留低嘅影,係迴圈行過嘅證據;keeper 由頭到尾知道,所以佢「remembers the road you did not take」。成場朝聖由「解謎」改寫成「履約」。

- **起**:Vigil 黎明,keeper 交出燈籠武器,鏡頭刻意喺空嘅 Rose Window 框停一拍。開場前插一幕彩玻璃神話:一團火被切成六點火星向西散落——玩家會當佢係遠古背景。keeper 送行嗰句:「行到道門識得你為止。」(同掌燈人尾句押韻,埋伏)。
- **承**:六條 quest = 誓文六句:每完成一條,Vigil 嘅 quest memory 散文除咗記事,仲會浮出一行「窗上鉛字」。蒼白眾指上=指住你出發嘅門;自身之影=之前迴圈嘅你,「憶中○○」係迴圈記憶;篡位者嘅無焰提燈=某個失敗迴圈留低嘅鑰匙(whisper 4 字面化);第八凶兆=道門沿迴圈投返落嚟嘅影;無法辨讀之頁=誓文嘅草稿,愈近迴圈閉合愈讀得明;掌燈人五個代價係剝到淨返「本焰」,因為道門只認原火。
- **轉**:第六 Shard unsealing:六格亮起後,mural 鉛線重新排列,拼出封門誓文全文——keeper 逐句讀出,玩家發現字字就係六條 quest memory 累積嘅句子,係「自己嘅手筆」。Rose Window 同冠冕上嘅門同步脈動,一窗兩面首次揭穿。玩家伸手掂玻璃,玻璃背面有一隻蒼白嘅手同時掂返過嚟——鏡位講明:嗰隻手嘅袖,係你件袍。
- **合**:Act IV【窗背】五節點:(1) 穿窗入鏡像世界,24 句 whisper 倒序重播;(2) 影最後一次現身,今次同你並肩行,明文提返三次被殺(rubric recurring);(3) 冷燈之原——歷代失敗迴圈嘅無焰提燈成野,篡位者嗰盞喺其中;(4) 終點之上嘅梯,每級一格玻璃重演一條 quest memory;(5) 門前。終戰【誓像】:鉛條鑄成你剪影嘅像,全套「憶中○○」招式,勝利=證明歸來嘅火同立誓嘅火係同一團。結局:門開向 Vigil 上空,你散落六點火星、將燈籠沿 Rose Window 遞落去俾下一個(=開場嘅)自己,末字係 whisper 23「The climb continues」改讀成誓文最後一句。

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「Its inscription has waited longer than the Vigil.」→ 唔係「碑文好古老」——誓文喺迴圈原點、Vigil 出現之前由你寫低,所以佢「等得耐過 Vigil」係嚴格因果陳述,唔係修辭。
- 「Light the panes. The door will know you.」→ 「know」由客套變字面:道門真係認得你,因為誓言係你手筆、六 pane 係你本焰切出;掌燈人一早講咗答案,只係無人當真。
- 「We were never climbing out. We were carrying light to the lock.」→ 影嘅 final 句原來係迴圈嘅全貌:朝聖從來唔係逃出去,係送火返自己寫低嘅鎖;「we」係歷代迴圈嘅每一個你。
- 「A pale hand has touched the dark side of the glass.」→ 玻璃暗面嗰隻手就係你:Act IV 你企喺窗背,unsealing scene 掂玻璃嗰下係呢句 whisper 嘅正拍——兩隻手係同一隻。

**Act IV 概念**:新 region【窗背】:彩玻璃嘅背面世界,構圖全鏡像、鉛線變成地形。九敵=未點亮嘅 pane 人形(素玻璃、無色,借「the colour the Spire refuses to name」做佢哋缺失嘅色)。Boss【誓像】:窗框鉛條鑄成嘅玩家剪影,行為係「驗證」而唔係「阻止」——用晒憶中招式,考歸來嘅火係咪立誓嗰團。

**敗仗殘留 (A3)**:每次敗仗=迴圈多行咗一圈:Vigil 石上多一道刻痕,keeper 明文講返「上次你喺(死亡地點)熄咗」,而該次死亡會實際生成 quest 2 世界觀下嘅一個影——敗仗唔係失敗,係誓文多寫一筆,回讀時全部係迴圈證據。

**風險(agent 自報)**:閉合迴圈天然風險係「一切早已注定=無 stakes」,結局要靠「履約嘅選擇感」補救;同 baseline C 嘅「第一個朝聖者」味道有少少近,要靠「誓文逐句浮現」呢條 UI/文本管線拉開——呢條管線係實作成本,quest memory 散文要逐句對齊誓文,寫作精度要求最高。
