## 15. 《《切火之人》》 (The Firecutter)

**Film DNA**:Shutter Island × Oldboy——主角就係罪人,成個「任務」係為佢度身設計嘅刑期(Shutter Island);而法庭(掌燈人)一路陪住你分期收贖款,你唔知自己喺度服刑(Oldboy 嘅「懲罰早就開始咗」)。呢個係 baseline C 嘅激進深化版,深化咗三樣:(1) C 冇答「點解道門要封」——因為你:你當年將供養門上嗰樣嘢嘅一團火切成六 pane 散走,令佢斷糧成個紀元;(2) Sovereign 以肉身封門唔係擋「佢」,係等「你」——佢同時係封印同通緝令;(3) roguelite loop 本身=判刑,你每次「贏」殺 Sovereign,就係罪犯再一次擊倒等緊佢自首嘅人。

**Logline**:你唔係去開門嘅英雄,你係返嚟自首嘅縱火犯——六塊 shard 係你當年切碎嘅贓物,Sovereign 企咗喺門口成千年,唔係擋住上面嗰樣嘢,係等你揹返啲火返嚟。

**結局先行**:Asset:sovereign.png(斷 halo、右上缺格)+ mirror.png。最後一幕:你將第六塊 shard 舉高——唔係嵌落 Rose Window,而係啱啱好補入 Sovereign halo 右上嗰個缺口。佢冇還手,除低冠,講:「The mask is broken. Look above.」然後散開。你經過鏡,鏡入面個黑影終於除低兜帽——同你而家一模一樣,微笑,因為佢一直都知。反轉全句:「第六塊 shard 唔係鎖匙,係贓物——你唔係嚟開門,你係嚟自首。」

**反轉本體**:Page 1 嗰句被動句(「六 pane 由一團火切出,喺第一次 Vigil 之前被散落」)冇講邊個做——因為 agent 係你。你係第一次 Vigil 之前嘅切火者:將供養「門上嗰樣嘢」嘅一團火切成六份散走。Sovereign 係第一個目擊者兼第一個朝聖者(C 嘅定義保留),以肉身封門封咗成千年,等犯人返嚟。揭後回讀改寫晒:三個影=之前唔肯認罪嘅你;掌燈人五代價=五期贖款(火、財、身、恩、光——你搶走乜就賠返乜);每次殺 Sovereign 嘅「勝利」=又一次拒捕;所有「收集 shard」嘅英雄敘事,一夜之間變成「歸還贓物」。

- **起**:Vigil,你喺 rose window 前醒,手心攥住一塊唔記得點嚟嘅 emberglass 碎屑;窗上六格得返輪廓,冇色——因為色係畀你抽走咗。路上第一場戲用 woundedKnight.png:垂死騎士遞出琥珀水晶,講:「還返去……你識路㗎——你行過。」玩家當佢認錯人。
- **承**:Quest 2 三個影係證人:「I remember the stone.」——石就係門前案發現場;quest 5 五頁其實係判詞散頁(page 3 企住死嗰個朝聖者=第一個發現你罪行嘅人,即後來嘅 Sovereign);quest 6 五代價=五期賠償,同你當年搶走嘅五樣嘢一一對應;quest 3 嘅無焰提燈=案發時你用嚟運火嘅器皿(merchant 檯底收埋嗰件 cold thing);quest 4 第八凶兆=門上嗰樣嘢餓到開始投影落嚟。24 句 whispers 做 pacing:0-7 建世界、8-15 語氣轉向「有嘢記得你」、16-23 回讀之下直接係一張通緝令。
- **轉**:第六 Shard unsealing scene 就係 ending_first 嗰幕本身(先寫結局嘅正正係佢):shard 補 halo、Sovereign 除冠散去、鏡中人除帽。跟住門開——門後唔係神唔係魔,係一團餓到得返一粒嘅火:你當年斷佢糧嗰樣嘢。「上面嗰樣嘢」呢個空白位,答案係一個受害者。
- **合**:Act IV【還火之路】五節點:揹住六 pane 嘅光行「終點之上嗰段梯」(page 3 直接兌現),每節點熄你一格資源——鏡像掌燈人五代價,今次冇得講價;中段三個影逐個現身讓路,逐個講返你當年三步:點樣切、點樣散、點樣走。終戰 boss=【餓火】:佢唔想殺你,佢想食你身上六 pane,戰鬥機制係你邊打邊決定畀唔畀。全還=ascended.png(黎明金城:火歸位,世界第一個真正嘅早晨);打贏佢而唔還=fallen.png(黑曜廳:碑係 Sovereign 嘅,碑腳孤燈係你留低嘅道歉——你贏咗,但你又一次走咗)。

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「六 pane 由一團火切出,喺第一次 Vigil 之前被散落」→ 被動句係敘事詭計:成句冇 agent,因為 agent 就係讀緊呢句嘅你。
- 「I remember the stone. You walked away before I stopped calling.」→ 由怨靈碎語變成案發證詞:the stone 係門前祭石,「叫緊你嗰個」係俾你斷糧、仲未斷氣嘅火——你個影記得你點樣行開。
- 「The gaunt keeper remembers the road you did not take.」→ 你冇行嗰條路=當年自首嗰條。掌燈人由怪人變成記咗你條數千年嘅執行官。
- 「The dead climb twice: once in flesh, once in memory.」→ Roguelite loop 嘅判詞:肉身行完,記憶再行——呢句就係你刑期嘅定義,由第 3 場勝利已經宣咗畀你聽。
- 「The mask is broken. Look above.」→ 由「假王被拆穿」變成任務完成報告:面具(通緝令)功成身退,「望上面」係叫你去面對受害者。
- 「Your monument does not always lie down.」→ 你嘅紀念碑唔係瞓喺地下嘅墓碑——係企咗喺門口成千年嘅 Sovereign:你嘅罪本身企咗喺度等你。

**Act IV 概念**:【還火之路】——appended 短終章:一段懸空玻璃梯 region(直接兌現 page 3「終點之上仲有一段梯」),9 敵=你當年散火時餓壞燒傷嘅殘存物,冇一隻主動追擊,全部係行近先攻擊嘅哀兵——敵人設計本身就係控訴;boss=【餓火】,核心機制係「畀/唔畀」嵌入戰鬥回合。

**敗仗殘留 (A3)**:每次敗仗,Vigil 散文句以第一人稱記低「我今次又冇還到」,rose window 對應格閃一下然後再暗——賠償進度可視化;woundedKnight 第二次會面明文提返:「你上次喺【某 act】跌低——唔緊要,贓物唔會爛。」

**風險(agent 自報)**:「玩家=罪犯」係三個之中最重口味,直接挑戰玩家嘅英雄 fantasy,處理唔好會變成指控玩家;深化 C 即係同 baseline C 綁死,主持人唔揀 C 呢版冇得獨立存在;「每 run 殺 Sovereign=再犯案」要 Act IV 畀返玩家真選擇(還/唔還)先托得住,否則只係一味內疚。
