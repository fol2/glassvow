## 12. 《《你嘅碑唔會躺低》》 (Your Monument Does Not Lie Down)

**Film DNA**:Memento——借「主角無法儲存記憶、靠自留筆記行動、最後發現成單任務係自己寫俾自己嘅謊,而佢揀繼續」:Vigil journal=紋身同拍立得,結局二選一就係 Leonard 揸車離開嗰一下——知道真相之後,自己揀信邊個版本。

**Logline**:每個 run 都以為係第一次嘅朝聖者,喺門後搵到一排自己嘅碑,先知六 shard 任務係歷代自己寫低留俾自己嘅禮物——而佢要再揀一次:帶住記憶走,定係立碑、忘記、再嚟過。

**結局先行**:最後一幕:門開,fallen.png 全幅——黑曜石碑大廳,一排企立嘅碑,每塊碑腳一盞熄咗嘅黑燈籠(deeds 嗰盞),最近嗰塊碑腳嘅孤燈仲着緊。keeper 喺門邊輕聲:「呢盞,係你上次留低嘅。」反轉全句:「你唔係第一個朝聖者——你係唯一嗰個,嚟緊第 N 次;每次你都開到門,每次你都揀忘記,親手散落六塊 shard、將任務重新寫俾自己。門後從來冇答案——朝聖本身,就係你留俾自己嘅禮物。」

**反轉本體**:反轉:玩家歷代已經完成過呢場朝聖無數次。每次去到門後見到碑廊,都揀抹憶重來:散 shard、僱蒼白眾揹碎片落山重置棋盤(page 2 嘅「揹落嚟」原來係你落嘅單)、喺 journal 寫低新一輪任務。揭咗之後要重讀:六條 quest 全部係自己留俾自己嘅字條;shade 三殺係同最近三代嘅自己交手;merchant 個「無焰提燈」係上代你寄賣俾下代你嘅遺物;keeper 唔係嚮導,係你僱嚟看住個 loop 嘅管理人;連「Continue Climb 唔好 Begin Anew」都變成 diegetic 警告。

- **起**:玩家喺 Vigil 醒,枱上一本 journal,自己筆跡:「相信呢本簿。集齊六塊 shard,開封門。」再落一行細字:「唔好問 keeper 佢記得幾多。」keeper 遞早餐咁淡定:「你噚日,都係咁樣問我。」——玩家以為係講尋日,其實係講上一代。
- **承**:六條 quest 重讀成六張自留字條:蒼白眾收 mote=回收你上次散落嘅殘屑;自身之影三次會面=最近三代你嘅殘影,佢哋招式叫「憶中○○」因為淨係佢哋仲記得,臨死嗰句「Each climber leaves a shape behind」係人口普查唔係哲理;Usurper 條線係你上代設計嚟提自己「王座係假嘅、答案唔喺冠上面」;Lamplighter 五個代價每代照收,佢係唯一由頭收到尾嘅債主;Unreadable Page 五頁=你歷代留低、斬件收藏嘅真相,分五場先解封係你自己設計嘅防劇透機制;第八凶兆係 loop 用舊嘅磨痕。
- **轉**:第六 Shard unsealing scene:六格逐格燃亮,但鏡頭俾玩家見到一樣嘢——玻璃背面有舊燈嘅煙漬:每格都係「重新」燃亮,唔係第一次。keeper 企喺你側邊,講出全個故事第一句穿崩嘅話:「同上次一樣咁靚。」玩家第一次聽到「上次」。
- **合**:Act IV【碑廊】:五個節點行過一排排你嘅碑(whisper 10 字面化:碑全部企立),每個節點一段 event——讀返一代 journal 嘅殘頁,對應五頁真相;敵人係唔肯瞓低嘅碑同歷代殘影。終戰 boss【首行者】:第一代嘅你,唯一冇抹憶、一直坐喺碑廊記住晒嘅嗰個(mirror.png 鏡中淺笑黑影人嘅正身),佢唔係想殺你,係想有人終於帶住記憶行出去代佢完場。勝出後二選一:立碑抹憶再散 shard=fallen 畫面收結,journal 重寫,遊戲 diegetic 咁重開新 run(NG+ 本身就係結局);帶住記憶走出去=ascended.png,黎明=第 N+1 個朝早、第一個記得嘅朝早,Vigil 從此空置。

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「Your monument does not always lie down.」→ 反轉前似 deed 彩蛋嘅怪話;反轉後係地理事實:門後碑廊啲碑係企立嘅——而且全部係你嘅,複數。「not always」係克制講法:一塊都冇躺低過。
- 「Each climber leaves a shape behind.」→ 反轉前係泛指眾生嘅哲理;反轉後係精確陳述:每個 climber 都係你,每代留一個 shape——你打嗰三隻影就係最近三代,仲有更多喺碑廊等緊。
- 「Five pages make a chapter; five prices make a confession.」→ confession 係字面:Lamplighter 每代照收五筆,佢嗰疊收據就係你歷代嘅供詞——證明你每一代埋單嗰刻都心知門後有乜,只係下一代唔認數。
- 「We were never climbing out. We were carrying light to the lock.」→ 「we」唔係修辭性複數,係真係好多個你;「never climbing out」係坦白——歷代冇一個真係想出去,因為行出去先係朝聖嘅終結,而朝聖本身先係你哋留俾自己嗰份禮物。

**Act IV 概念**:【碑廊】:門後嘅黑曜檔案廳,以 fallen.png 做基調延伸——排碑、熄燈、玻璃塵。九隻敵人方向:唔肯瞓低嘅碑(石+鉛線構成)、歷代朝聖者殘影(重用 hero 兩 aspect 剪影變體)、燈籠食卡怪(deeds 嗰盞「食緊卡嘅燈籠」升做敵種)。boss【首行者】=第一代你,mirror.png 黑影人正身,戰鬥用晒你歷代 build 嘅招。

**敗仗殘留 (A3)**:Memento 便條系統:每場敗仗後,journal 自動多一行「你自己筆跡」嘅註腳,內容指明該場敗仗(「唔好喺 Leviathan 之前燒盡 embers」),而下一 run 呢張字條真係會喺對應位置彈出——敗仗嘅 residue 係你寫俾下一個自己嘅實用遺言,玩家死得多,journal 就越似一個人嘅一生。

**風險(agent 自報)**:「門後冇獎賞」係三個之中最大膽亦最易嬲親玩家嘅一步——如果「朝聖係禮物」呢個情感落唔到地,玩家會覺得被呃咗成個 game;另外 NG+ 作為 diegetic 結局要真係實裝(journal 重寫、字條系統延續)先圓得到,純過場交代唔住。
