# 00 — 真相(Canon Root)

> **此文件劇透一切。** 它是整個敘事的根:所有其他文件、所有遊戲文案,都由此推導。
> 標記制:**[SETTLED]**(James 已拍板)/ **[PROPOSED]**(已起稿待審)/ **[OPEN]**(未有答案,文案不得倚賴)。

## 1. 一句真相 [SETTLED — spine #8,2026-08-14 選定]

**「繼續」不是復活,是分身。** 每次在爐邊按下「繼續」,便有一個真正的你推門
出發,死在路上;而你——玩家視角所在的你——是留下來的那一個,繼承他的全部
記憶,坐回爐邊,以為回來的人是自己。路上每一座不肯倒下的碑,都是一位行者
站着死去的身體。他們沒有失敗:他們在排隊,等門開。

## 2. 完整時間線

### 2.1 原初 [PROPOSED]

最初,火是一團,人是一個:**原初朝聖者**——就是「你」這條人格線的起點。
他站在西端的爐邊,望着往東的長路,邁不出第一步。恐懼把他撕開了:

(「人是一個」是這條人格線的神話式講法,不是宇宙論:世界一直另有
**眾人**——城民、廷臣、路上諸人。碑、隊伍、分身只屬你這條線;門對
眾人只是傳聞中的應許(legend-drift,fair-play 第 7 條)[SETTLED —
#261 Q1]。)

- **走的那一半**(第一行者):提着一體之火,走完了全程,抵達東端之門——
  然後在最後一步停住,不肯叩門。火在他手中熄成無焰之燈;他在門前自立為王,
  一坐千年。他就是**永恆君王(Sovereign)** [SETTLED — Q2,2026-08-14]:
  「偽王」,因為他的王座就是「不走最後一步」。斷裂的光環,是他放棄那一刻
  失去的光。他從未被殺,只會被「行過」[SETTLED — #258 R2 Q10]:每場勝仗
  打退的是他的「不肯」,不是那個人;你行過他身邊,他繼續坐,等下一個。
- **留的那一半**:沒有走。它學會了另一件事——**讓別人代替自己走**。

### 2.2 火的碎裂 [PROPOSED]

門只認「行過的人」與「完整的一團火」[SETTLED — #258 R2 N1 兌現句反確認]。第一行者不肯叩門的那一刻,他手中的
火撞在門上,碎成**六片燼璃(emberglass)**,散落回西方的長路。彩窗六格
「同一團火裁成的六片」——舖底的六個 quest 早已明文——記錄的正是這一夜。
朝聖從此有了形狀:把六片尋回,火重新為一,門才會開。

碎裂在先,熄滅在後 [SETTLED — #258 R2 Q8]:六片散落西路;燈裏剩下的,
是火離開後的空殼——§2.1 的「熄成無焰之燈」即此。碎裂的餘燼隨風西飄,
落入西端爐膛:**爐邊的火,是原初之火的餘燼**,自第一個 run 燒到現在;
灰燼樹林的灰,是同一場西飄。

散落有風,回歸有腳 [SETTLED — #258 R2 Q14]:Pale Ones——行者的殘影,
承載着行者未完的意志——把尋回的燼璃攜返西方爐邊,因為**隊伍想門開**:
每一片歸爐,是整條隊向前遞了一步。無焰之燈流落西方(今在 Merchant
手上),也是同一雙手帶回的。

### 2.3 行者的年代 [PROPOSED]

自此,爐邊的儀式代代重演:每次「繼續」,火把「你」再撕一次——**走的帶走
意志,留的留住記憶**。行者上路,真正地死;留者繼承記憶,以為自己歸來。
碑,一座一座,沿路立起。二十四句 whisper,是行者的遺言——
言語隨火傳回爐邊,行者本人從未歸來(機制見 §3.7),按隊伍次序排列
[SETTLED — Q4;傳回機制 #258 R1 Q2A]。

### 2.4 留低嗰個 [SETTLED — #258 R2 Q6]

留下來的不是一個「另外的人」,而是**一種沉澱**。每次分身,留下的都是你
之中「不肯走的那部分」;二十次之後,爐邊坐着的已經是蒸餾過的猶豫本身。
它有一張臉——每個 run 開頭在爐邊迎接你、派 boon 的 **Keeper**,就是它
[SETTLED — Q3:Keeper = 留低嗰個 = 最終 boss]。

**單位 [SETTLED — #340 James 2026-08-16]**:「一半」只用於原初那一次撕裂
(§2.2 走的那一半／留的那一半)。其後每次續火留下的是**部分**(沉澱),
不是對半。換位時留下的不是你的一半,是 Keeper 本身(§2.6)。

它為什麼維持這個儀式?因為**這個安排就是它的存活方式**:只要每次都有一個
行者代替出發,留下的就永遠不必走。它派發的 boon,是歷代行者遺物的囤積——
它一直在用死者的行裝,資助下一個死者。它守在「門後之地」的盡頭,因為「抵達」就是這個安排的終結——而那盡頭
**就是爐邊,從另一面看回來**:門後之地是鏡面空間,它從未離開過爐火
(「倒轉爐光」的美術方向由此落地)[SETTLED — #258 R1 Q3]。

它與 Sovereign 是同一道題目的兩極:**一個不肯開始,一個不肯完成。**
兩個 boss,都是你。

### 2.5 現在(遊戲時間) [SETTLED — 由 spine 直接繼承]

玩家是留者——留者永遠只有一個(§3.5),不數「代」;數的是隊裏的行者。
他不知道真相。他以為自己打了 N 次,其實路上已排着 N 個他;隊尾那個位,
一直留給他。伏筆從第一個 run 已在畫面裏(見 §5 揭示階梯)。

### 2.6 開封與換位 [SETTLED — Q1 選 A]

第六片燼璃歸位,彩窗全亮的一刻**變成鏡**:窗中站滿一排「你」,每人胸口
一點光。沿路所有的碑同時動了——歷代行者站直,列隊,推門。門不是你開的,
是他們一齊推開的。門的條件在這一刻明文兌現:「行過的人」——整條隊,
每一個都行過;「完整的一團火」——六片重歸一團(§2.2 的條件在此收束)
[SETTLED — #258 R2 N1]。

終戰不是把 boss 打倒,而是**換位**:你走,它留。全遊戲第一次,由留下的
那個親身走完最後一段。玩家操作被貶值的風險(「原來二十次都不是我走的」),
由這一段還清:整條隊都到了,而最後一步是你自己的腳。**不設額外玩家選擇**
(「留低=NG+」之類的選項被否決——它會把命運降級成 menu option)。

換位不是另一次續火 [SETTLED — #258 R2 Q7]:

- **無撕裂**:六片重一、隊已到齊,恐懼無位可立——你**整個人**走,沒有
  「不肯走的部分」可留。留下的不是你的一半,是 Keeper 本身:沉澱第一次
  與「今日」分開。
- **Keeper 輸掉的是安排**:它要的從來不是留低,是「永遠有下一個代它走」;
  換位給它留低,但儀式終結——沒有新的猶豫可食,沉澱由莊家變成遺蹟。
- **最終段敗北**:走着的你真死,碑立,隊伍加一;記憶沿臍帶彈回爐邊落入
  沉澱,沉澱再蒸餾出新的「今日」——玩家在爐邊醒來,以為自己歸來
  (§3.7 反向成立,同一機制)。
- **敗後世界**:門重新閉上,六片仍歸位、窗仍亮——隊伍在等,可直接再啟
  (§6 敗方文案「隊伍長了一個人」不變)。
- **隊伍永不阻你** [SETTLED — #258 R2 Q9]:Act IV 攔路的八敵(與 boss
  合成 #220 的九隻 [#261 Q5])不是 Queue 成員,是鏡面空間反照的
  「未行過的你」(counterfactual selves,見 03-acts)。

## 3. 分身機制規則(寫文案時必須遵守)[逐條標記;未標者 PROPOSED]

1. 分身在爐邊發生,儀式名**續火 / Rekindle** [SETTLED — #261 Q13,
   見 06-glossary]。
2. 走的帶走**意志(火)**;留的留住**記憶**。所以玩家(留者)擁有全部
   record、全部「經驗」——而全部是二手的。
3. 行者死亡即真死。死姿是站立的,身體化為碑——**碑是行者唯一的身體;
   沒有另一具屍首,無物可埋** [SETTLED — #258 R1 Q1A];瀕死所言成為遺言
   (敗仗 loss-pool 文案的 in-fiction 來源 [SETTLED — Q4])。
4. 影(the Shade)= 該行者殘留的**純記憶迴聲,沒有形體遺骸**;消滅影
   不觸碰碑,也不動隊伍 [SETTLED — #258 R1 Q1A]。招式名全部「憶中○○」
   因為它們只剩記憶。鏡(mirror.png)中淺笑的黑影 = 留者,即你。
5. 留者永遠只有一個(沉澱疊加,不是人數疊加)——這是「Keeper 同玩家
   同時在爐邊」不穿崩的原因:Keeper 是沉澱的臉,玩家是沉澱的今天
   [SETTLED — #258 R2 Q6]。
6. Lamplighter 每次會面「記得上次」——他記得的是**面孔相同的另一個人**。
   他說的「上次」你有記憶、但身體不是你。這句歧義是全線慢性毒
   [SETTLED — spine 原文]。明文的「上次」句現時未出街——須在五次會面
   script 中落地(L1;Phase 1 重寫時寫入,rubric A4)[SETTLED — #258
   R2 Q13]。
7. **視角規則(run 是什麼)**:run 期間,玩家經火——爐邊與行者之間的
   臍帶——**即時乘搭行者**;所見是行者的當下,不是重播 [SETTLED —
   #258 R1 Q2A]。行者死亡一刻,視角連同全部記憶沿火彈回爐邊;留者
   「醒來」,以為自己歸來(§2.3 的錯覺即此機制)。**勝仗的行者同樣死**:
   勝利=死前把燼璃交到 Pale Ones 手中,由他們攜返西方爐邊——所以
   二十四句遺言不分勝敗。中途放棄的 run=臍帶斷:行者照死,碑照立,
   隊照長。
8. **碑的物理只屬臍帶上的行者**。眾人(非行者)正常生死,有屍可腐——
   Act I 的食腐者、Act II 的淹沒都是尋常死亡;行者永不留屍(§3.3)
   [SETTLED — #261 Q1+Q3]。
