# 01 — 世界(表面敘事 vs 真相)

> 派生自 `00-truth.md`。此文件管理「玩家在每個階段**以為**的世界」——
> 寫任何一句文案前,先查這裏:該階段的玩家信念是什麼,句子不得超前洩露。

## 表面敘事(玩家被告知的版本)[文本 PROPOSED;渠道紀律 SETTLED — #259 Q1]

西端有守夜之爐(Vigil),東方長路盡頭有一道封門。一團火曾被裁成六片
燼璃,散落於路;朝聖者一次次出發,尋回碎片,點亮彩窗,直到門開。
死亡不是終結——爐火會把你喚回,記憶無損,再走一次。

**渠道紀律 [SETTLED — #259 Q1]**:本段是 writer-facing 推導基準,
**不是待寫的 copy**。「喚回」永不明文入句——解釋復活機制的句子一律
當 leak 處理;copy 只可*預設*它,永不*陳述*它(「爐火會復活你」)。
roguelite 慣例本身承載表面敘事:Prestige 的觀眾不問箱裏那個去了
哪裏,正因為沒有人提過那個箱。

**字面真確警告(#259 verify 修正)**:「喚回」「再走一次」在 00 §1
之下**不是字面真**——行者真死不歸(§3.3),留者從未出發(§2.5);
「回來」本身就是全局錯覺。所以「預設」的資格按 channel 分開:

- **Keeper 一句都不可以**——fair-play 第 3 條(可誤導、不可講大話)
  連假預設都禁:寫「你醒了」,不寫「你回來了」。
- 其他角色與環境文案可自由承載錯覺:他們真心信它(00 §4 矩陣),
  屬 legend-drift(fair-play 第 7 條),照常入 ledger。

(「記憶無損」獨一字面為真——留者確實繼承全部記憶,00 §3.2。)

## 地理 [鏈+鏡面空間 SETTLED — #258 R1 Q3;窗門同體+城 SETTLED — #259 Q3+Q4]

橫向朝聖,西 → 東:

```
【守夜之爐 Vigil】— 灰燼樹林(I)— 沉沒之城(II)— 黑曜王庭(III)—【封門】— 鏡中歸途(IV)— 金城
```

- **彩窗與封門是同一道 threshold 的兩面** [SETTLED — #259 Q4]:西面
  是爐邊彩窗(Rose Window),東面是東端封門——「西東在鏡中相接」是
  物件事實,不是光學巧合。火在東面撞碎,六片歸位嵌回西面六格:
  **碎於此門,歸於此窗**。開封之刻,隊伍在路上「推門」與玩家在爐邊
  見「窗成鏡」是同一件事;玩家由窗步入 Act IV。Act IV 的視覺語法是
  「倒轉的爐光」。
- **鏡中歸途是鏡面空間,上圖鏈末段不是直線**:IV 的盡頭=爐邊,
  從另一面看回來(00 §2.4 [SETTLED — #258 R1 Q3])。五節點=同一條
  路由另一面走回——「倒轉爐光」的每一格,都是正路某段的鏡像
  [SETTLED — #259 Q4]。
- **金城=守夜之爐的真貌** [SETTLED — #259 Q3]:ascended.png 的
  雲海金城,是爐邊由鏡面另一面看的樣子;入城=歸家;整條朝聖路是
  一個圈。「金城不是新地域」由此釘實——它是全遊戲第一個地點,
  從最後一面看。「金城 / the Gilded City」是眾人的 legend 名
  [SETTLED — #261 Q12]:真身無另名——它是守夜之爐。
- 舊垂直語彙(climb/spire/above)全數退役,逐句處理見 ledger。

## 火的物理 [SETTLED — #259 Q5+Q6;水方程 #261 Q4]

七條方程,100K 字的 metaphor 詞彙全部由此取:

- **火 = 意志**(動)。
- **玻璃 = 凝固的火 = 記憶**(火停下來的形狀)[#259 Q5]:「記憶是火
  燒過後留下的東西」與「玻璃是凝固的火」是同一句——**記憶就是凝固的
  意志**。燼璃(emberglass)= 一體之火凝在撞門一刻,所以它既是火的
  碎片、又是那一夜的記錄:雙重身份是定義,不是巧合。each pane 各對應
  一個 quest 線。
- **灰 = 燒盡、無可凝者**(意志耗盡後的殘餘;Act I 的物料)。
- **水 = 不燒也不凝的意志 = 「等」** [SETTLED — #261 Q4]:意志不行
  (不燒)、又不肯死心凝成記憶(不凝),便浮起、積聚、上升——
  沉沒之城淹於自己的等待(Act II 的物料)。淹死的等待者仍在走動,
  因為他們的「等」未散——與影同族不同科:影是凝過之物的迴聲,
  他們是從未凝過之物的殘留。派生詞:鏽=等待對器皿的慢蝕;
  假光=似光而不透意志的模仿(deepmaw 的燈)——正因無意志可透,
  反過來教玩家「光=意志透物可見」這條規則。
- **黑曜 = 凝而無光的玻璃**(被放棄的意志;Act III 的物料)。
- **燈 = 攜帶意志的器皿**;無焰之燈 = 意志已離開的器皿(Sovereign;
  以及 darkWalker 的黑燈)。
- **光 = 意志透物可見** [#259 Q6]:玻璃透光=記憶仍讓意志通過;黑曜
  不透光=不再讓意志通過的記憶(放棄的形狀);胸口一點光=未完的意志
  (Pale Ones 承載的那樣);斷光環=放棄一刻熄掉的光;窗逐格亮=火
  逐片歸位、透回出來。

**碑的語彙紀律** [#259 Q5]:碑歸「凝」族(「凝住的行者」),但 canon
不斷言物料——資產不改,文案取「凝」,不取「石/玻璃」實詞。
