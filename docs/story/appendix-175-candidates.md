# 家族:身份系 (Shutter Island / Fight Club / Memento)


## 1. 《燈中人》 (The One in the Lantern)

**Film DNA**:Fight Club:成個故事同你交易、幫你、問你收錢嗰個人,原來就係你自己嘅另一半。借法:主角(火)同空燈掌燈人(肉身)係同一個朝聖者一分為二;五次收費係 Tyler 式嘅「自己資產轉返俾自己」。

**Logline**:一個無臉朝聖者揹住盞點着嘅燈籠向東行,先發現自己唔係揸燈嗰個人——係燈入面嗰團火。

**結局先行**:先設計嘅最後一幕:emberglass-mural.png 六格全亮、輪轂拱門發光,掌燈人喺 Rose Window 前打開佢盞空燈,主角成件袍即場塌落變一堆空布,玩家視點由胸口琥珀核心流入燈籠。真正終幕二選一:ascended.png(黎明大教堂,前景係終於有面有火嘅掌燈人提燈入城,燈入面係你)或 fallen.png(佢喺碑前熄唔捨得熄,留低碑腳一盞孤燈)。反轉全句:「佢五次收費唔係收你嘅嘢——係收返佢自己;你由頭到尾都唔係朝聖者,你係朝聖者盞燈入面嘅火。」

**反轉本體**:hero 兩個 aspect 都蒙面無臉,因為根本冇面:玩家角色係一團被裝入軀殼嘅燈火,而沿路五次問你收費嘅空燈掌燈人,先係嗰個朝聖者本人——一個俾火離開咗嘅空殼。揭咗之後全部前文要重讀:武器係一盞點着嘅燈(你嘅本體先係武器,件袍先係容器);五個代價(embers、金、max HP、開局 boon、燈籠淨一格)唔係勒索,係肉身逐件收返自己嘅人性;影嘅招名全部「憶中○○」因為記憶屬於肉身唔屬於火,所以影記得石頭而你唔記得;deeds 入面「熄咗嘅黑燈籠」「食緊卡嘅燈籠」全部變成火嘅族譜;deepmaw/leviathan 嘅假誘餌燈變成「假光」母題嘅反面教材。

- **起**:開場喺 Vigil 外圍:垂死騎士(woundedKnight.png)遞出一塊琥珀水晶,水晶嵌入你胸口,你先「醒」——袍企起身,燈籠流星錘着火。掌燈人企喺遠處,打開佢盞空燈朝住東面,講:呢條路食光,六塊 shard 先叫得醒道門。反轉前呢幕係「接棒使命」;反轉後係「火由一個垂死容器交去下一個容器」,而掌燈人由第一秒已經望住屬於佢嘅嘢。
- **承**:六 quest 全部掛喺「光同容器」呢條線:蒼白眾唔獵你只指上(佢哋跟光行);自身之影係肉身喺沿路留低嘅記憶殘影,所以佢用你嘅招而你唔認得段記憶;篡位者嘅無焰提燈揭到假王,因為假光呃唔到道門——同一個邏輯最後揭埋你;掌燈人五次會面每次收一件「人先有嘅嘢」,吐一句線索,交易感情逐次由陌生變得詭異咁似「執屋」;無法辨讀之頁要焙住你嘅火先讀得出。第八凶兆係門影伸手搵自己團火。
- **轉**:第六 Shard unsealing scene:mural 六格逐格着,輪轂拱門發光;掌燈人最後一次現身,唔係收費——佢打開空燈對正你。你件袍塌落,鏡頭由琥珀核心流入燈籠,mural 玻璃上第一次映出一張面:掌燈人嘅面,而家俾燈光照亮。佢講反轉全句。之後封門開,四 act 永久生效。
- **合**:Act IV【無窗之地】五節點:重新合體嘅朝聖者提住你行過一個得返窗框冇玻璃嘅國度(呼應 whisper「Six spaces wait where no window stands」),九隻敵人係未被點亮嘅影,中途一節俾玩家用「火」視點操作(卡牌照舊,敘事換位)。終戰 boss【第一爐火嘅灰】——所有 pane 由一團火切出,上面嗰樣嘢就係俾火離棄咗嘅原初空框,佢餓。結局二選一:你注入空框,世界黎明(ascended.png);或者朝聖者閂燈,揹你行返落山,喺碑前留一盞小燈過世(fallen.png)。

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「A lantern without flame is still a key.」→ 反轉前係講篡位者 quest 嗰盞無焰提燈。反轉後係講掌燈人本人:佢就係一盞冇咗火嘅燈,而燈——有火冇火——始終係鎖匙嘅另一半;道門等緊嘅係燈同火重逢。
- 「Light the panes. The door will know you.」→ 反轉前係任務指示。反轉後「the door will know you」係字面意思:道門認得嘅從來唔係朝聖者,係光;佢識你,因為你就係當年由嗰團火切出嚟嘅嘢。
- 「The first keeper gave you a boon. Give me the gift, not the gratitude.」→ 反轉前係古怪收費台詞。反轉後:個 boon 本來就係俾「佢」——完整朝聖者——嘅;佢收返自己份禮物,而唔要感激,因為感激先係你(火)僅有嘅、真係屬於你嘅嘢。
- 「The gaunt keeper remembers the road you did not take.」→ 反轉前係神祕預言。反轉後:「你冇行過嘅路」係肉身嗰條路——佢記得,因為行嗰個係佢;你哋本來係同一個行路人,一個攞咗記憶,一個攞咗光。

**Act IV 概念**:新 region【無窗之地】:整個世界得返鉛框同石拱,冇一塊玻璃——彩繪玻璃美術嘅負片,天上係六個空窗位排成環。九敵係「未點亮嘅影」(現有影系 palette 反白)。boss【第一爐火嘅灰】:一個籠罩喺空框中央嘅灰白餘燼巨影,冇面,胸口一個同你一樣嘅琥珀凹位——你嘅形狀就係佢身上缺嗰一件。

**敗仗殘留 (A3)**:死亡=火熄。每次敗仗後返 Vigil,掌燈人盞空燈入面多一撻煙灰印,而佢第二次見面起會明文提返上次:「我尋晚由【沉沒之城】水底捧你返嚟——同水講咗聲唔好意思。」死喺邊個 act,佢句台詞同煙灰印位置就對應邊度;roguelite 迴圈 diegetic 化為「肉身逐次揹熄咗嘅火行返西面」。

**風險(agent 自報)**:最大風險係玩家 agency:「你唔係人,係火」如果收得唔好會令玩家離心,unsealing 嗰下必須即刻俾返操作權(Act IV 換位視點要做得順)。另外 duskblade aspect 兜帽入面係金 shard 唔係火,要用「光嘅另一形態」圓,同埋掌燈人現有 SVG 立繪未必撐到「有面被照亮」一刻,大概率要一張新立繪。


## 2. 《退位儀式》 (The Abdication Rite)

**Film DNA**:Shutter Island:成個世界係一場為主角一個人而設嘅角色扮演,所有人都知情、都做緊戲,目的係令佢自己行到嗰個佢一直拒絕嘅真相前面。借法:三 act 朝聖係 Vigil 眾人一次又一次重演嘅「退位儀式」,而病人係你——The Eternal Sovereign 本人。

**Logline**:你以為自己係一次又一次上去弒王嘅朝聖者,直到成個世界除低面具跪低——原來王一直喺樓梯下面,係你。

**結局先行**:先設計嘅最後一幕:第六 Shard unsealing,mural 六格全亮嗰刻,在場所有 NPC(蒙面 merchant、fleshTrader、骷髏 gambler、tidecaller、掌燈人)逐個除低面具——下面全部係蒼白面容——然後跪低,面向嘅唔係道門,係你;mural 輪轂拱門暗落去變成 mirror.png:鏡中黑影人發光眼淺笑,而佢嘅剪影同 sovereign.png 完全重疊。真正終幕:除冠行入門=ascended.png(黎明之城迎返佢失落嘅王);戴返個冠=fallen.png(黑曜大廳,臣民喺碑腳留一盞燈,儀式下個 run 再嚟)。反轉全句:「你每次上去斬嗰個王座上嘅嘢,係你自己披喺鎖上面嘅形;真王由第一日起就喺樓梯下面,揸住盞燈——成場朝聖,係你嘅子民第 N 次陪你行嘅退位儀式。」

**反轉本體**:玩家係 The Eternal Sovereign。好耐之前你攞咗一盞空燈籠、將王者嘅形披喺道門嘅鎖上面,自己封死咗成個世界嘅出口;蒼白眾同 Vigil 所有角色係你嘅子民,佢哋設計咗一場可以無限重演嘅朝聖儀式——換裝、派 whisper、逐格點窗——目的唔係殺你,係氹你自己行上去、親手拆穿個假王、最後自願除冠。揭後回讀:hero 蒙面無臉同 sovereign.png 無臉係同一張「冇面」;每次 run 打嘅 Sovereign 只係道具面具;merchant 同 fleshTrader 全部戴 pale 面具因為佢哋落妝先係真面目;開場嗰下「著袍」原來係「著龍袍」;連敗仗都係「今次儀式又失敗,執返個台」。

- **起**:開場喺 Vigil:蒙面 merchant 幫你扣好兜帽、遞上燈籠流星錘,鞠躬——低咗半寸,耐咗半秒。掌燈人喺 Rose Window 六個空格前面講:「東面有個假王,同埋一道俾佢封住嘅門。」第一句 whisper 落。反轉前呢幕係英雄着裝;反轉後係朝臣服侍君主更衣,嗰半寸鞠躬係宮廷禮數收唔住手。
- **承**:六 quest 係儀式嘅六個站:蒼白眾公然指上(佢哋係提場,唔使遮掩);自身之影係歷次失敗儀式留低嘅你,所以每個影都用你嘅招;篡位者 quest 係儀式核心一課——俾你親手用無焰提燈拆穿個道具王,教識你「個冠係假嘅」;第八凶兆係佢哋加落七個之外嘅記號,焗你喺門影下打一場、抬一次頭;無法辨讀之頁其實係儀式劇本,捱過五場先俾你讀;掌燈人五個代價係逐件剝走你嘅「王產」(embers、金、血、boon、燈火),等你行到門前一無所有——一個冇嘢好守嘅王先除得低個冠。
- **轉**:第六 Shard unsealing scene:六格點齊,眾 NPC 除面具、露出蒼白面容、向你跪低;mural 輪轂拱門化作 mirror.png,鏡中發光眼黑影淺笑,剪影同 sovereign.png 重疊,再同你重疊。掌燈人最後一個除面具,講反轉全句。門開,但門唔係出口——係你王座背後嗰道你封咗嘅門。
- **合**:Act IV【加冕之前】五節點:行入你封印嘅世界——加冕之前你屬於嘅地方,九敵係唔肯散場嘅儀仗(冠、杖、袍化形)。終戰 boss【不肯除冠嘅你】:最後一個影,着住完整王袍,用鏡像招式,打贏佢=打贏自己嘅不甘。結局:除冠行入去,ascended.png——黎明之城唔係天堂,係你退位後先入得返嘅家;或者戴返個冠封返道門,fallen.png——臣民喺黑曜大廳碑腳留一盞燈離開,下一個 run,儀式由頭嚟過(roguelite 迴圈 diegetic:每個 run 都係又一次 intervention)。

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「The Sovereign is a mask worn below the final stair.」→ 反轉後成句變晒字面:王座上真係得一個「mask」——件道具,「worn」係披喺鎖上面;而真正戴住王者身份、行緊最後一段樓梯嘅,係樓梯下面提燈嗰個你。
- 「The mask is broken. Look above.」→ 反轉前係假王死前嘅怪異遺言。反轉後係提場對白:面具着(戲服)每次俾你打爛,入面嗰個蒼白眾義工照劇本提你「望上面」——望你自己封嗰道門,望你唔肯認嘅嗰樣嘢。
- 「The Pale Ones are not hunting you. They are pointing upward.」→ 反轉後:佢哋梗係唔會獵殺你——你係佢哋個王。指上唔係預言,係成個儀式唯一嘅目的:引你自己一步步行上去,行到肯除冠為止。
- 「Each climber leaves a shape behind.」→ 反轉後:歷次退位儀式嘅 climber 由頭到尾都係同一個人——你。所以沿路每個影都用你 aspect 嘅招,招名全部「憶中○○」:全部係你上幾次儀式嘅殘留。

**Act IV 概念**:新 region【加冕之前】:門後係加冕之前嘅世界——未成形嘅琉璃,熔融、透光、未上色,同三 act 嘅彩繪成對比。九敵係化形儀仗(浮冠、遊杖、空袍),boss【不肯除冠嘅你】用 mirror.png 語彙:黑影、發光眼、你嘅完整招式表。五節點入面有一節係「無戰鬥嘅覲見」:蒼白眾列隊送行,逐個講一句佢哋喺儀式入面做過嘅角色。

**敗仗殘留 (A3)**:每次敗仗,骷髏 gambler 喺 Vigil 更新佢塊粉牌:「第 N 場,冧喺【沉沒之城】,賠率照舊」——死喺邊、輸俾邊個 boss 都上牌;第二次同佢見面起佢會明文提返上次(「上次都係嗰條喉吞咗你」)。反轉前讀係賭鬼講風涼話,反轉後讀係儀式紀錄員記低第 N 次失敗嘅 intervention,同一句嘢兩個溫度。

**風險(agent 自報)**:兩大風險:一,同 baseline C 一樣以 Sovereign 做支點(C 係「王=第一個朝聖者頂住門」,呢個係「王=你,世界=做戲」——機制唔同但主持人多數只能二揀一);二,Shutter Island 式「全部係戲」好易 deflate 三 act 嘅 stakes,必須守住「代價全部係真」呢條線(HP、embers、死亡真扣真痛),戲係真戲、傷係真傷,先至企得住。


## 3. 《忘誓者》 (The Forgotten Vow)

**Film DNA**:Memento:主角用自設嘅筆記系統操縱自己嘅無知,真相係「佢一早知道,係佢揀咗唔記得」;最後一擊係佢明知係假都揀繼續個 loop。借法:24 句 whispers、五頁、第八凶兆全部係你毀約自抹之前留俾自己嘅 dead-drop 線索網,而結局俾你 Leonard 式再揀一次。

**Logline**:你跟住沿路嘅耳語同斷句集齊六塊 shard,先發現拆散呢把鎖嘅、寫低呢啲線索嘅、同埋抹走自己記憶嘅——三個都係你。

**結局先行**:先設計嘅最後一幕:emberglass-mural.png 六格全亮後,六格玻璃自己播返一段彩繪玻璃動畫——一個兜帽剪影(你嘅形)由內向外擊碎 Rose Window,將六塊 shard 交落跪住嘅蒼白眾手上,向掌燈人逐一交低五件代價,最後舉起燈籠對正自己個兜帽,白光一閃,空住對眼向西行。真正終幕二選一:記返起、明知係乜都行上去=ascended.png;或者再斬一次「記得嘅自己」、揹六塊 shard 落山重新散落=fallen.png(碑係你自己立俾自己嘅空墳,碑腳孤燈係你留返俾下一個自己嘅提示)。反轉全句:「六塊 shard 從來唔係鎖匙——係你當年親手拆散嘅鎖;你唔係第一次企喺呢道門前,你係企返喺你自己毀約嘅位。」

**反轉本體**:你上過去、開過道門、見過上面嗰樣嘢——然後你落咗個誓:唔可以俾佢跟落嚟。你擊碎 Rose Window,命蒼白眾將六塊 shard 揹落山散開(所以佢哋而家逐粒 mote 咁「還」返俾你),搵掌燈人收起你嘅人性做按金,再用自己盞燈抹走自己嘅記憶。但你入面有一半唔甘心,喺抹憶之前沿路留低咗 24 句 whispers、五頁撕開嘅告解、同第八個記號。揭後回讀:成個遊戲係「過去嘅你起嘅保安系統」俾「而家嘅你」逐層拆除,而啲 whisper 係第三把聲——嗰個想俾人搵返嘅你。自身之影係被剪走嘅記憶(所以招名全部「憶中○○」,佢記得石頭、你唔記得);篡位者個假王係你裝落去嘅 decoy;掌燈人每收一件代價吐一句線索,係按你當年份合約分期還你自己嘅告解。

- **起**:開場喺 Vigil:一地霜霧,一個蒼白眾跪低,雙手捧住一粒 pale mote 遞返俾你——似還嘢多過似獻祭。Rose Window 六個空格旁邊有一句刻痕(whisper 0),筆跡你唔識,但唔知點解睇得明。你乜都唔記得,得知一樣嘢:要向東行。反轉前係標準失憶開局;反轉後:佢真係還緊嘢俾原主,而嗰句刻痕係你自己隻手刻嘅。
- **承**:六 quest 係你自設嘅 dead-drop 網:蒼白眾收九粒 motes=逐件收返你當年分俾佢哋守嘅嘢;自身之影三殺=遺忘機制反撲,被剪走嘅記憶唔想俾你剪第二次;篡位者=你親手拆自己裝嘅 decoy 王;第八凶兆=你留低嘅里程碑,焗自己喺門影下打一場先信;無法辨讀之頁揹住贏五場先讀得出——你設咗個門檻,確保讀到告解嗰個「你」捱得起真相;掌燈人五個代價逐次還,每還一件人性你就近真相一步。24 句 whispers 順序派,就係你寫俾自己嘅分期路書。
- **轉**:第六 Shard unsealing scene:六格逐格亮,然後合埋播返記憶動畫(見 ending_first)——碎窗、託孤、交按金、白光、西行。輪轂拱門打開,唔係因為鎖匙啱,係因為把鎖終於重新完整,而佢認得整佢嗰個人。掌燈人喺你背後講出最後一句線索之外嘅第一句真話:「你叫我哋咁做。你仲叫我哋,唔好話你知。」
- **合**:Act IV【未忘之峰】五節點:門後係你未擊碎嘅記憶起嘅峰上之峰(第三頁嗰個站着死去嘅朝聖者見到嘅嗰段梯),九敵係九個【被剪走嘅時刻】,每個掉低一句你毀約前嘅記憶散文。終戰 boss【冇忘記嗰個你】——mirror.png 語彙,鏡中黑影發光眼淺笑,佢由第一 act 個 mirror event 笑到而家。結局:同佢合體、記晒起、明知上面係乜都開門=ascended.png;或者再殺佢一次、揹 shard 落山重散、抹走呢一輪嘅自己=fallen.png,而「The climb continues」由安慰變成你親手揀嘅無限 loop——同時 diegetic 咁解釋咗點解仲有下一個 run。

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「Broken glyphs are the shadow of a complete sentence.」→ 反轉後:嗰句「complete sentence」係你毀約前寫低嘅完整告解;24 句 whispers 同滿地斷符全部係你自己拆散自己嘅句子——個「影」嘅本體,係你隻手。
- 「THE EIGHTH OMEN WAS NEVER AN OMEN. IT WAS THE SHADOW OF A DOOR.」→ 反轉前係世界觀大揭示。反轉後連呢句「更正」都係你留低嘅路標:你早知七個 omen 唔夠說服健忘嘅自己,所以加多第八個,焗未來嘅你肯企喺門影下面打嗰一場、親眼確認。
- 「We were never climbing out. We were carrying light to the lock.」→ 反轉前係悲壯使命宣言。反轉後係字面自首:歷代嘅「we」全部係你,一直做緊同一件事——將光搬返去你自己整嘅鎖度;「never climbing out」,因為個 loop 由頭到尾係你揀嘅。
- 「Your monument does not always lie down.」→ 反轉前係怪談。反轉後:你座碑會企起身行路,因為你根本未死——fallen.png 嗰座黑曜碑係你立俾自己嘅空墳,碑腳孤燈係你每次重新抹除自己之後,留返俾下一個自己嘅一點提示。

**Act IV 概念**:新 region【未忘之峰】:用「完好無缺嘅彩繪玻璃」做視覺反差——三 act 全世界都係碎裂鉛框,呢度嘅玻璃完整、飽和、刺眼,因為係未碎嘅記憶。九敵【被剪走嘅時刻】各自係一幕定格玻璃畫活化。boss【冇忘記嗰個你】直接沿用 mirror.png 嘅黑影+發光眼+淺笑語彙,招式表同玩家完全鏡像。

**敗仗殘留 (A3)**:每次敗仗,Vigil 嘅玻璃牆多一組 broken glyphs——一句「斷咗嘅句子」,圖案剪影對應你死喺邊個 boss/邊個 act,掌燈人會明文提:「尋晚又多咗一行,唔係我刻嘅。」反轉前係詭異環境敘事;反轉後玩家發現嗰啲全部係自己夜晚刻嘅(blackout),即係話成個 residue 系統本身都係反轉嘅證物,死得愈多、告解愈長。

**風險(agent 自報)**:同 baseline B 共用「記憶」做原料,要講清分別:B 係死者行返段憶,呢個係在生嘅人自願自抹+自設線索,方向啱啱相反,但主持人要提防兩個一齊上檯會撞味。另一風險係 Memento 結構嘅爽位依賴玩家肯回讀 24 句 whispers,casual 玩家可能 miss 咗大半伏筆;Act IV「完整玻璃」美術同記憶動畫係全新資產,成本唔細。

# 家族:時間因果系 (Predestination / Source Code / Butterfly Effect)


## 4. 《自書之誓》 (The Vow That Wrote Itself)

**Film DNA**:Predestination:自我成因嘅閉合迴圈——主角追尋嘅源頭就係自己。呢度借「炸彈客=特工=自己」嘅結構:門上嘅誓言、散落六 shard 嘅嗰隻手、「上面嗰樣嘢」,三者全部係玩家自己喺迴圈另一端嘅同一個動作。

**Logline**:朝聖者行到封門前,發現門上等咗比 Vigil 更耐嘅誓文係自己親手寫低——而開門呢一下,正正就係當初六塊 shard 被散落嗰一下。

**結局先行**:最後一幕用 emberglass-mural.png:六格全亮,輪轂正中嘅發光拱門打開——但門後唔係彼岸,係由上空俯瞰嘅 Vigil 黎明,鏡頭穿過拱門、由 Rose Window(rose_window_view)嘅背面走返出嚟。玩家親手將六點火星向西撒落地圖(開場神話嗰一幕,而家先知係邊個做)。反轉全句:「道門唔係出口——道門係起點;你而家開門呢一下,就係六塊 shard 當初被散落嗰一下。門上嘅誓言,係你自己嘅手筆。」

**反轉本體**:Rose Window 同「冠冕之上嘅封門」係同一面窗嘅兩面:Vigil 唔係喺終點西面,係喺終點之上。「上面嗰樣嘢」就係你——迴圈原點嘅你,將自己嘅燈火切成六塊、寫低誓言封門、然後無記憶咁向西出發。揭後回讀:六條 quest 線唔係六件奇聞,係誓文嘅六句;掌燈人五個代價唔係勒索,係逐層剝走「唔屬於原焰嘅嘢」;每次死亡留低嘅影,係迴圈行過嘅證據;keeper 由頭到尾知道,所以佢「remembers the road you did not take」。成場朝聖由「解謎」改寫成「履約」。

- **起**:Vigil 黎明,keeper 交出燈籠武器,鏡頭刻意喺空嘅 Rose Window 框停一拍。開場前插一幕彩玻璃神話:一團火被切成六點火星向西散落——玩家會當佢係遠古背景。keeper 送行嗰句:「行到道門識得你為止。」(同掌燈人尾句押韻,埋伏)。
- **承**:六條 quest = 誓文六句:每完成一條,Vigil 嘅 quest memory 散文除咗記事,仲會浮出一行「窗上鉛字」。蒼白眾指上=指住你出發嘅門;自身之影=之前迴圈嘅你,「憶中○○」係迴圈記憶;篡位者嘅無焰提燈=某個失敗迴圈留低嘅鑰匙(whisper 4 字面化);第八凶兆=道門沿迴圈投返落嚟嘅影;無法辨讀之頁=誓文嘅草稿,愈近迴圈閉合愈讀得明;掌燈人五個代價係剝到淨返「本焰」,因為道門只認原火。
- **轉**:第六 Shard unsealing:六格亮起後,mural 鉛線重新排列,拼出封門誓文全文——keeper 逐句讀出,玩家發現字字就係六條 quest memory 累積嘅句子,係「自己嘅手筆」。Rose Window 同冠冕上嘅門同步脈動,一窗兩面首次揭穿。玩家伸手掂玻璃,玻璃背面有一隻蒼白嘅手同時掂返過嚟——鏡位講明:嗰隻手嘅袖,係你件袍。
- **合**:Act IV【窗背】五節點:(1) 穿窗入鏡像世界,24 句 whisper 倒序重播;(2) 影最後一次現身,今次同你並肩行,明文提返三次被殺(rubric recurring);(3) 冷燈之原——歷代失敗迴圈嘅無焰提燈成野,篡位者嗰盞喺其中;(4) 終點之上嘅梯,每級一格玻璃重演一條 quest memory;(5) 門前。終戰【誓像】:鉛條鑄成你剪影嘅像,全套「憶中○○」招式,勝利=證明歸來嘅火同立誓嘅火係同一團。結局:門開向 Vigil 上空,你散落六點火星、將燈籠沿 Rose Window 遞落去俾下一個(=開場嘅)自己,末字係 whisper 23「The climb continues」改讀成誓文最後一句。

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「Its inscription has waited longer than the Vigil.」→ 唔係「碑文好古老」——誓文喺迴圈原點、Vigil 出現之前由你寫低,所以佢「等得耐過 Vigil」係嚴格因果陳述,唔係修辭。
- 「Light the panes. The door will know you.」→ 「know」由客套變字面:道門真係認得你,因為誓言係你手筆、六 pane 係你本焰切出;掌燈人一早講咗答案,只係無人當真。
- 「We were never climbing out. We were carrying light to the lock.」→ 影嘅 final 句原來係迴圈嘅全貌:朝聖從來唔係逃出去,係送火返自己寫低嘅鎖;「we」係歷代迴圈嘅每一個你。
- 「A pale hand has touched the dark side of the glass.」→ 玻璃暗面嗰隻手就係你:Act IV 你企喺窗背,unsealing scene 掂玻璃嗰下係呢句 whisper 嘅正拍——兩隻手係同一隻。

**Act IV 概念**:新 region【窗背】:彩玻璃嘅背面世界,構圖全鏡像、鉛線變成地形。九敵=未點亮嘅 pane 人形(素玻璃、無色,借「the colour the Spire refuses to name」做佢哋缺失嘅色)。Boss【誓像】:窗框鉛條鑄成嘅玩家剪影,行為係「驗證」而唔係「阻止」——用晒憶中招式,考歸來嘅火係咪立誓嗰團。

**敗仗殘留 (A3)**:每次敗仗=迴圈多行咗一圈:Vigil 石上多一道刻痕,keeper 明文講返「上次你喺(死亡地點)熄咗」,而該次死亡會實際生成 quest 2 世界觀下嘅一個影——敗仗唔係失敗,係誓文多寫一筆,回讀時全部係迴圈證據。

**風險(agent 自報)**:閉合迴圈天然風險係「一切早已注定=無 stakes」,結局要靠「履約嘅選擇感」補救;同 baseline C 嘅「第一個朝聖者」味道有少少近,要靠「誓文逐句浮現」呢條 UI/文本管線拉開——呢條管線係實作成本,quest memory 散文要逐句對齊誓文,寫作精度要求最高。


## 5. 《立亡者》 (The Unfallen)

**Film DNA**:Source Code:成個重複迴圈其實發生喺一個垂死者嘅最後一刻入面,任務係喺重播中搵出唯一正確嘅一次;搵到嗰下,重播升格做真實。呢度將「八分鐘列車」換成「燈籠最後一格火」——每個 run 都係死火前嘅一次重播。

**Logline**:你以為自己死完又死;其實你喺終點企住死咗好耐——成條朝聖路,係你燈籠最後一粒火星入面重播緊嘅記憶,搵緊嗰一條可以點齊六 pane 嘅路。

**結局先行**:最後一幕用 fallen.png:黑曜石碑大廳,碑腳一盞孤燈——揭穿嗰下,鏡頭升起,石碑輪廓同 hero 剪影重疊:碑就係企住死嘅你,孤燈就係終於放得低嘅燈籠。反轉全句:「你冇喺條路上死過一次。你喺呢度企住死咗好耐——條路,係你燈籠裡面最後一格火重播緊嘅嘢。」coda 用 woundedKnight.png:嗰隻手終於垂低,向新到嘅朝聖者遞出琥珀水晶——玩家先發現 Act II 見過嘅垂死騎士 event,一直係結局嘅預告,遞水晶嘅係自己。

**反轉本體**:肉身早喺故事開始前已經企喺終點死去(頁三嗰個「站着死去嘅朝聖者」係第一身唔係第三身);Vigil、死亡回歸、24 句 whisper,全部係垂死之火嘅內部重播——whisper 係肉身臨終聽落嘅碎念,影係失敗重播嘅殘形,鏡中笑住嘅黑影係「重播之外」嘅真身。揭後回讀:roguelite 迴圈由 game mechanic 變 diegesis 本體;Source Code 式救贖在於——當六 pane 喺火中點齊,重播唔再係重播:火行返入肉身,身倒下,手張開,shard 交畀下一個真實嘅朝聖者,搵到嗰條路成為真。

- **起**:正式開場前閃一格:黎明逆光、一個人形企喺峰頂——一秒都無就切走。然後先係 Vigil「醒來」、keeper、燈籠、向東出發嘅正常 onboarding。早期 mirror.png event 照常出現:鏡入面嗰個發光眼黑影淺笑望住你,唔講嘢——玩家當佢係不祥,其實佢係鏡外嘅真身。
- **承**:六條 quest = 垂死之火嘅六個搜索條件,每條隔離一件「必須重新點着嘅記憶」:蒼白眾=肉身企喺終點時望住路過嘅其他朝聖者最後嘅光;自身之影=三次失敗重播嘅殘形(招名「憶中○○」係字面);篡位者=肉身生前信錯嘅假希望;第八凶兆=油盡燈枯嘅閃爍節拍,「八」係門影橫過垂死眼簾;五頁=企住死嗰段時間諗通嘅五件事;掌燈人五個代價=火同自己講數,逐樣放低(將來、財、肉、初贈、淨一格火)先可以繼續燒——佢尾句「Light the panes. The door will know you.」係肉身留畀自己團火嘅最後指令。
- **轉**:第六 pane 亮起嗰下,Vigil 場景明顯「跳格」——同一拍重播咗兩次,玩家第一次親眼見到世界係重播。鏡隨即向外碎開,露出真實時刻嘅峰頂黃昏:企住嘅人形,手中燈籠淨返一粒火星。keeper 講:「接落嚟呢程,唔係再一次——係嗰一次。」由今個 run 起,重播已搵到條路,而家要喺最後一粒火星入面真係行返一次。
- **合**:Act IV【燼梯】——頁三講嘅「終點之上嗰段梯」,喺最後一粒火星入面展開,五節點:(1) 世界邊緣開始燒燶、重播失去餘裕;(2) 掌燈人最後一面,明文認返五個代價其實係肉身逐樣放手(recurring recall);(3) woundedKnight 一幕倒帶重演,兜帽揭開係你嘅面具;(4) 鏡中黑影行出嚟,無言同行;(5)【不倒者】——你嘅肉身,被誓約鎖住企喺門前唔肯倒。終戰勝利=火行返入身。結局:身終於倒下、手張開遞出第六 shard,fallen.png 孤燈立碑,末句「The dead climb twice.」之後,大廳入口浮現下一個朝聖者剪影,接 whisper 23「The climb continues.」

**Misdirection audit(已 shipped 原句 → 反轉後讀法)**:

- 「Your monument does not always lie down.」→ 完全字面:你嘅紀念碑企緊——因為石碑就係你企住死嘅屍身;呢句由怪誕謎語變成劇透本體。
- 「The dead climb twice: once in flesh, once in memory.」→ 第一次係肉身嗰程(真實發生、以企住死終結);「in memory」唔係比喻——玩家打嘅每一個 run 就係第二次,喺記憶入面爬。
- 「Each climber leaves a shape behind.」→ quest 2 嘅三個影就係之前失敗重播留低嘅殘形;「shape」係重播殘影嘅準確描述,招名全部「憶中○○」一早寫明晒。
- 「有個朝聖者站着死去,見到終點之上仲有一段梯」→ 頁三一直用第三身讀;揭後變第一身——嗰個朝聖者係你,嗰段梯就係 Act IV【燼梯】,而「見到」嗰下就係成個遊戲發生嘅時刻。

**Act IV 概念**:新 region【燼梯】:峰頂之上、火星內部嘅一段梯——幾何邊緣燒燶、背景係放大嘅燈芯同玻璃熔光。九敵=前三 act 敵人嘅「燒剩」白燼變體(記憶燒緊嘅殘形,美術上可重用剪影+燼白 palette)。Boss【不倒者】:玩家肉身本體,持熄燈、誓約鎖姿,唔攻擊為主而係「唔肯倒」——打法係解鎖而唔係擊殺。

**敗仗殘留 (A3)**:每次敗仗=一次重播熄火:鏡面(Vigil 面鏡/mirror event)多一道裂紋,而該次敗走嘅 run 會具體化成 quest 2 世界觀下嘅影——之後遇到嘅影會用返你敗嗰 run 用開嘅牌型招式,「憶中○○」直接指涉該敗仗;keeper 講返「上次你熄喺(地點)」。
