## 主要人物

### Keeper /【留低嗰個】 [身份 SETTLED — Q3;內容 SETTLED — #260 Q1/Q2/Q7]

- **是什麼**:歷代分身中「不肯走的那部分」的沉澱,有了臉。每個 run 開頭
  在爐邊迎接你、派 boon;最終 boss;lite-Hades 的「大廳裏那位」。
- **想要**:安排永遠繼續——有人代走,它就不必走。它不恨你;它**是**你,
  而且真心待你好,這正是最難堪之處。**關懷與麻醉同時為真** [SETTLED —
  #260 Q1]:關懷是真的(它就是你錫自己);同一份關懷也是令安排行落去的
  麻醉劑。兩讀並存,不揀——這正是「揭後更冷」的燃料。
- **知道**:一切(全知者)。
- **聲線** [SETTLED — #260 Q2]:溫厚、疲倦。四條規則:
  1. 從不說謊——只說雙關(fair-play 第 3 條)。
  2. 每句話都要通過「揭後重讀依然成立而且更冷」的測試。
  3. 永不催促你出發(催促會穿崩——它需要你出發,但必須顯得是你自己要走)。
  4. **永不以第一身講路**:它的行路記憶全部是繼承的二手記憶,自己從未
     行過;明知而稱「我行過」即說謊,第 1 條已禁。只有「你行過幾多次」,
     永無「我哋嗰陣」。揭後翻聽先發現它由頭到尾冇認過一步。
- **資產** [SETTLED — #260 Q7]:兩件新繪——①爐邊兜帽坐像(L0-safe:
  兜帽,面孔永不可見,黑洞面同 Lamplighter 一樣;即 00 §5 L0「爐前兜帽
  身影」的本體);②Act IV boss form。兩件**同一剪影**,揭場一眼認得。
  boss form 刻意犯 style-bible「enemy 不得用 keeper/warden 剪影」的禁例
  ——認出嗰下就是設計本身;生成時在 `docs/art-ledger.md` 記 waiver。
  爐火本身是它的第二張臉(不變)。

### 空燈掌燈人 Hollow Lamplighter [A4 錨點 SETTLED;內容 SETTLED — #260 Q3]

- **是什麼**:路上的老者,五次會面,每次索一個代價。唯一貫穿五次、明文
  「記得上次」的 recurring anchor(rubric A4)。
- **想要**:替他的空燈找回火——表面如此。揭後:他一直在為行者送行;
  他見過太多「同一張臉」,他的代價是一場認人啟事,想確認你是不是同一個。
- **知道**:不知機制;見過人變成碑。門的條件只有傳聞版本(00 §4
  hearsay [#258 R2 Q11])。誠實的錯誤見證人——他說的每句都真,
  結論都錯。
- **聲線**:老派、具體、只談看得見的東西(燈、油、路、面孔)。歧義來自
  事實本身,不來自修辭。
- **五價約束** [SETTLED — #260 Q3]:Phase 1 五次會面 script 的五個代價
  **逐次貼身**——由身外物到切身之物,因為認人認得越嚟越急。
- **資產**:`hollow-lamplighter.svg` + 彩窗第六格(向火伸手的人)。

### 永恆君王 Sovereign [SETTLED — Q2]

- **是什麼**:第一行者。走完全程、在門前停住不肯叩門的那一半「你」。
  偽王;第三 act boss。
- **想要**:表面:守住王座。實況:千年來在等下一個走到門前的人——等人
  證明最後一步是走得出的,或者證明他當年停下是對的。
- **知道**:一切關於門的事(親身付不起那個價)。
- **聲線**:莊嚴的自辯。從不稱自己是王以外的東西;對「行」這個字有
  生理性的迴避。迴避的落地方式 [SETTLED — #260 Q4]:**中途換詞**——
  他會講「去」「到」「抵達」,句式繞開,永不結巴;尊嚴保住,迴避先至
  是揭後先睇得出的 tell,不是當場笑位。英文版 rewrite 同樣令 "walk"
  缺席(重現迴避,非逐字譯)。
- **資產**:`sovereign.png`(冠、笏、**斷裂光環**——放棄那一刻失去的光);
  無焰提燈(彩窗第三格)。

### 影 The Shade [SETTLED — #260 Q5]

- **是什麼**:上一位行者殘留的**純記憶迴聲,沒有形體遺骸**;Own Shade
  quest 三次「殺自己」的對象——其實你在熄滅自己身上仍記得怎樣行的那
  部分。碑才是行者唯一的身體;消滅影不觸碰碑(00 §3.3–3.4
  [SETTLED — #258 R1 Q1A])。
- **聲線**:碎句、現在完成式、只有第二人稱。「I remember the stone.
  You walked away before I stopped calling.」是全 cast 最重一句——控訴
  對象是玩家。**此句是 L1 的重量天花** [SETTLED — #260 Q5;
  範圍依 #258 per-channel ceiling 收窄至 L1]:凡比它更明的 cast 句必須
  定級 L2 以上並服從 04-delivery 的 per-channel ceiling;canon-lint 以
  此句作 L1/L2 界的比對錨(00 §5 L1 同記)。
- **資產**:`shade.png`、`mirror.png`(鏡中淺笑黑影=留者,即你);
  招式名「憶中○○」系列。
