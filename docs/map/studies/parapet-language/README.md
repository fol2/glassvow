# Parapet language — controlled native comparison

Owner approved preparing three bridge-parapet directions before applying one to the chapter. This isolated fixture compares A (blind recessed arch bays), B (two broad open arches per bay), and C (three finer arches per bay). It is not an extracted generated route or a chapter integration.

All six 1458 × 820 captures share the same bridge, structural arches, stairs, traveller, chapter materials, lighting and frozen shared water time. Only central parapet bays change. Close orthographic size is 12; game-distance size is 19, matching the current study's ordinary camera size. Stair handrails are deliberately common to all candidates.

Run `godot --path . --rendering-method mobile -s res://tools/map_workshop/parapet_study/run.gd` to reproduce all six captures. Both scripts passed the explicit-path parser check. Native captures were visually inspected; a coplanar stair/platform finish was corrected before the final capture. Tailnet A/B/C and camera controls were exercised successfully. The current Act II review and shared water module were not modified.

Recommendation: B as the principal language, A for short enclosed approaches; C only as a possible landmark detail. The owner selected B. Its Act II application is now being reviewed; this does not approve the complete chapter. Adapting bays to bends, crossings, generated lengths and actual clearance audits follows the design decision; no production qualification is claimed for this fixture.
